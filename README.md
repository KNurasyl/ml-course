# ML и LLM — курс «LLM-инженер: от модели до сервера»

**Начни с [course/START.md](course/START.md)** — одна страница: цель, карта уровней и следующее занятие. Её же первой показывает учебник [START_HERE.html](START_HERE.html), который открывается двойным щелчком без интернета.

Всё работает на ноутбуке и бесплатно. Прежние уроки, математика и вводные занятия доступны целиком в разделе «Библиотека» учебника.

Сборка, проверка материалов и история версий — в [MAINTAINING.md](MAINTAINING.md).
