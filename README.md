# ML и LLM — локальный самоучитель 1.0.0

**Открой [START_HERE.html](START_HERE.html) двойным щелчком в папке курса.** Это локальный учебник с оглавлением, поиском, уроками и заданиями. Для чтения не нужны сервер, аккаунт или интернет. Исходный [учебный маршрут](course/README.md) можно читать и в редакторе Markdown.

## Начать самостоятельно

1. Прочитай [порядок обучения и самопроверки](course/self-study.md).
2. Выполни [диагностику](course/diagnostic.md), сохрани ответы, затем сравни с ключом.
3. Открой [P01](course/pilot/P01.md) и выполняй практику по порядку.
4. После своей попытки используй [решения](solutions/pilot/answer-key.md), затем решай новый вариант и заполняй [журнал](progress/progress.md).

Проверка наставником для перехода дальше не требуется. Помощь можно получить по желанию. Самопроверка, независимое подтверждение навыка и готовность к работе учитываются отдельно.

## Практика без ручной настройки пути

Открой **[START_PRACTICE.cmd](START_PRACTICE.cmd)** из проводника двойным щелчком. Он запустит Jupyter с существующим окружением и правильной папкой. Окно запуска оставь открытым. В браузере выбери notebooks → pilot → P01.ipynb.

Если используешь PowerShell, эта команда работает из любой папки:

```powershell
& "C:\projects\ml-llm-course\.venv\Scripts\python.exe" -m jupyterlab --ServerApp.root_dir="C:\projects\ml-llm-course"
```

Перед редактированием сделай копию задания внутри submissions. Исходники находятся в notebooks/pilot; эталоны — в solutions/pilot. Относительные ссылки в исходном ноутбуке рассчитаны на его папку. Из перемещённой копии переходи к теории через учебник.

Python 3.11.9 и зависимости уже установлены в .venv. Обязательный первый цикл работает на CPU и локальных данных, без платных сервисов. Для восстановления окружения из папки курса:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\bootstrap.ps1
```

## Что готово

- Десять полных занятий P01–P10: объяснения, разобранные примеры, практика, самостоятельные работы, подсказки и новые варианты.
- Диагностика, словарь и ключи для самостоятельной проверки.
- Десять рабочих ноутбуков и десять отдельных эталонов.
- 17 полных модулей, 85 уроков: собственная теория, численные примеры, упражнения, самостоятельные задачи и отдельные решения. В каждом модуле — домашняя работа, рубрика, повторная и отложенная проверка.
- 85 статических учебных рисунков и 17 интерактивных экспериментов с параметрами; отдельная CPU-лабораторная для каждого модуля.
- Эталон голосового HR- и backend-тренажёра: настоящая локальная LLM, поиск, Vosk и Windows SAPI; отдельные рубрики и синтетические наборы обоих направлений.
- Локальные копии каталога бесплатных ресурсов, исследования вакансий и методической основы.

Материалы можно проходить целиком самостоятельно. Учебный пилот с твоими ответами и персональная калибровка пока не проведены. Готовность материалов, освоение навыков и профессиональный грейд учитываются отдельно.

## Оригиналы и копии

| Материал | Где редактировать |
| --- | --- |
| Уроки, диагностика, словарь, программа | course/ |
| Ключи решений | solutions/pilot/answer-key.md и solutions/modules/ |
| Личный журнал | progress/progress.md |
| Работы и копии ноутбуков | submissions/ |
| Код и исходные лабораторные | src/, notebooks/, labs/, projects/ |
| Реестр локальных материалов | metadata/material-registry.json |
| Программа и зависимости | curriculum.json |
| Связи заданий, файлов и версий | course-manifest.json |

**Markdown — оригинал, START_HERE.html — генерируемая копия для чтения.** После изменения текста или журнала выполни:

```powershell
.\.venv\Scripts\python.exe tools\build_reader.py
.\.venv\Scripts\python.exe tools\build_manifest.py
```

Затем обнови учебник в браузере. HTML не записывает ответы и прогресс автоматически.

Историческое происхождение материалов хранится только в metadata/source-pages.json. Старые удалённые копии больше не являются актуальным учебником. Временная .authoring содержит архив создания: её старые генераторы нельзя запускать для пересоздания текущих материалов.

## Проверка материалов

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\verify.ps1
```

Отдельно:

```powershell
.\.venv\Scripts\python.exe tools\build_reader.py --check
.\.venv\Scripts\python.exe tools\validate_course.py --require-local
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools\run_notebooks.py --kind all --html
```

Исполненные копии сохраняются в artifacts/executed. Автоматическое выполнение примеров не проверяет незаполненные ответы ученика. Для собственной реализации отдельной функции доступна tools/check_submission.py с задачами mse, gradient и predict; форма вызова описана в коде и заданиях.

Проверки структуры обнаруживают отсутствующий файл, битую локальную ссылку, неверную предпосылку, сетевую зависимость оформления и устаревшую копию учебника.

[Статус выпуска](RELEASE_STATUS.md) · [История изменений](CHANGELOG.md). Репозиторий локальный, удалённый origin не настроен.

## После первых десяти занятий

Переходи к [M00](course/modules/M00.md) и двигайся по M00–M16. Если понятия первых модулей уже освоены в пилоте, сначала реши самостоятельную задачу нового урока; правильный расчёт вместе с объяснением позволяет сократить повторное чтение. Нельзя пропускать новую тему только потому, что она знакомо называется.

В каждом модуле пять уроков. Открой его обзор, прочитай урок, попробуй численный пример, сделай свою работу в submissions, затем открой решения. Интерактивная демонстрация находится в конце обзора модуля, статические рисунки — прямо в уроках. Для запуска проверяемого примера:

```powershell
Set-Location C:\projects\ml-llm-course
.\.venv\Scripts\python.exe labs\M03\demo.py
```

Замени M03 на нужный модуль и прочитай его labs/Mxx/README.md. Эталонная лабораторная показывает ожидаемое поведение; запуск готового demo не заменяет самостоятельную реализацию. Результаты сохраняются в artifacts. Подробности LLM и речи, первая загрузка моделей и ограничения описаны в соответствующих модулях.

[Запуск эталонного голосового тренажёра](projects/interview_trainer/README.md). Для всего нового практического комплекта:

```powershell
.\.venv\Scripts\python.exe tools\run_labs.py
```

Первоначальный ориентир нагрузки: 400–600 часов вместе с практикой и собственным проектом, около 4–7 месяцев при 20–25 часах в неделю. Это оценка для планирования, а не обещанный срок; заменяй её измеренным временем из журнала. Часть математических тем может потребовать дополнительных дней.
