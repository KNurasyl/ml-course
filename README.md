# ML и LLM — локальный самоучитель 1.1.0

**Открой [START_HERE.html](START_HERE.html) двойным щелчком в папке курса.** Это локальный учебник с оглавлением, поиском, уроками и заданиями. Для чтения не нужны сервер, аккаунт или интернет. Исходный [учебный маршрут](course/README.md) можно читать и в редакторе Markdown.

**Оформление 2.0:** адаптивный технический учебник для компьютера и телефона. В начале урока есть результат и карта разделов, поиск ведёт к конкретному фрагменту, а из ответа можно вернуться к задаче или новому варианту B/C. Все 104 рисунка получили отдельные компоновки для широкой и узкой страницы; 26 опытов работают внутри урока без вложенной прокрутки. Если файл был открыт раньше, обнови вкладку. [Исправления 13 замечаний и браузерная проверка](quality/design-v2/audit-resolution.md).

## Начать самостоятельно

1. Прочитай [порядок обучения и самопроверки](course/self-study.md).
2. Выполни [диагностику](course/diagnostic.md), сохрани ответы, затем сравни с ключом.
3. Открой [P01](course/pilot/P01.md) и выполняй практику по порядку.
4. После своей попытки используй [решения](solutions/pilot/answer-key.md), затем решай новый вариант и заполняй [журнал](progress/progress.md).

Проверка наставником для перехода дальше не требуется. Помощь можно получить по желанию. Самопроверка, независимое подтверждение навыка и готовность к работе учитываются отдельно.

## Практика без ручной настройки пути

Открой **[START_PRACTICE.cmd](START_PRACTICE.cmd)** из проводника двойным щелчком. Он запустит Jupyter с существующим окружением и правильной папкой. Окно запуска оставь открытым. В браузере выбери notebooks → pilot → P01.ipynb.

Если используешь PowerShell, эта команда работает из любой папки:

```powershell
& "C:\projects\ml-llm-course\.venv\Scripts\python.exe" -m jupyterlab --ServerApp.root_dir="C:\projects\ml-llm-course"
```

Перед редактированием сделай копию задания внутри submissions. Исходники находятся в notebooks/pilot; эталоны — в solutions/pilot. Относительные ссылки в исходном ноутбуке рассчитаны на его папку. Из перемещённой копии переходи к теории через учебник.

Python 3.11.9 и зависимости уже установлены в .venv. Обязательный первый цикл работает на CPU и локальных данных, без платных сервисов. Для восстановления окружения из папки курса:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\bootstrap.ps1
```

## Что готово

- Десять полных занятий P01–P10: объяснения, разобранные примеры, практика, самостоятельные работы, подсказки и новые варианты.
- Диагностика, словарь и ключи для самостоятельной проверки.
- Десять рабочих ноутбуков и десять отдельных эталонов.
- 17 полных модулей, 103 урока: собственная теория, численные примеры, упражнения, самостоятельные задачи и отдельные решения. В каждом модуле — домашняя работа, рубрика, повторная и отложенная проверка.
- 103 рисунка к урокам и отдельный рисунок HW — 208 SVG для двух размеров страницы; 26 интерактивных экспериментов с параметрами; отдельная CPU-лабораторная для каждого модуля.
- Эталон голосового HR- и backend-тренажёра: настоящая локальная LLM, поиск, Vosk и Windows SAPI; отдельные рубрики и синтетические наборы обоих направлений.
- Локальные копии каталога бесплатных ресурсов, исследования вакансий и методической основы.

Материалы можно проходить целиком самостоятельно. Учебный пилот с твоими ответами и персональная калибровка пока не проведены. Готовность материалов, освоение навыков и профессиональный грейд учитываются отдельно.

**Markdown — оригинал, START_HERE.html — генерируемая копия для чтения.** После изменения текста или журнала выполни:

```powershell
.\.venv\Scripts\python.exe tools\build_reader.py
.\.venv\Scripts\python.exe tools\build_manifest.py
```

Затем обнови учебник в браузере. HTML не записывает ответы и прогресс автоматически.

Те же шаги и полную пересборку выполняет единая точка сборки `tools\build_all.py` с фиксированным порядком: интерактивные опыты (`build_visuals` → `build_module_visuals` → `build_product_visuals`) → рисунки (`build_foundation_figures` → `build_quantitative_figures` → `build_responsive_figures`) → учебник → manifest. Генераторы детерминированы: при неизменных исходниках полный прогон не меняет файлы.

```powershell
.\.venv\Scripts\python.exe tools\build_all.py --text-only
.\.venv\Scripts\python.exe tools\build_all.py
```

Первая команда — только учебник и manifest, её достаточно после правки Markdown или журнала. Флаг `--reports` дополнительно перезаписывает свидетельства выпуска в quality/ из artifacts/ полной проверки; он нужен только при подготовке выпуска. `--dry-run` показывает шаги без запуска. Разовые скрипты интеграции версии 1.1.0 перенесены в [tools/legacy](tools/legacy/README.md) — их не запускать.

Историческое происхождение материалов хранится только в metadata/source-pages.json. Старые удалённые копии больше не являются актуальным учебником. Бывшая временная папка .authoring с архивом создания перенесена в [archive/authoring-0.1.0.zip](archive/README.md): её старые генераторы нельзя запускать для пересоздания текущих материалов.

## Проверка материалов

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\verify.ps1
```

Отдельно:

```powershell
.\.venv\Scripts\python.exe tools\build_reader.py --check
.\.venv\Scripts\python.exe tools\validate_course.py --require-local
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools\run_notebooks.py --kind all --html
.\.venv\Scripts\python.exe tools\check_no_loss.py compare --before quality\snapshots\baseline-1.1.0.json
```

Уроки M09–M16 и все уроки-расширения с суффиксом X начинаются с блока «Версии и дата проверки»: какие версии пакетов и моделей проверены, когда и по какому источнику. `tools\check_freshness.py` сообщает об отсутствующем блоке как об ошибке, а о проверке старше шести месяцев — как о предупреждении; тот же контроль встроен в `validate_course.py --require-local`.

Последняя команда сравнивает текущие материалы со снимком выпуска 1.1.0 и завершается ошибкой, если пропал урок, задача A/B/C, файл решения, лабораторной, упражнения или ноутбука, тест либо уменьшилось число слов основного текста какого-либо Markdown-файла курса и решений. Перед правкой можно сохранить свой снимок: `tools\check_no_loss.py snapshot --out quality\snapshots\before-Txx.json`.

Исполненные копии сохраняются в artifacts/executed. Автоматическое выполнение примеров не проверяет незаполненные ответы ученика. Для каждого M00–M16 есть exercises/Mxx/starter.py, check.py и инструкция. Проверка получает путь к твоей реализации; отдельный полный эталон находится в solutions/exercises. Старые проверки mse/gradient/predict также сохранены.

Проверки структуры обнаруживают отсутствующий файл, битую локальную ссылку, неверную предпосылку, сетевую зависимость оформления и устаревшую копию учебника.

## После первых десяти занятий

Сначала выполни [CP0](course/checkpoints.md), затем переходи к [M00](course/modules/M00.md) и двигайся по M00–M16. Если понятия первых модулей уже освоены в пилоте, сначала реши самостоятельную задачу нового урока; правильный расчёт вместе с объяснением позволяет сократить повторное чтение. Нельзя пропускать новую тему только потому, что она знакомо называется.

С версии 1.2.0 этот принцип оформлен явно. Уроки P01–P10 и M00–M06 начинаются с блока «Проверь себя сначала» ([адаптивный маршрут](course/self-study.md#адаптивный-маршрут), [таблица после CP0](course/checkpoints.md)). Если ты уже делал RAG и интеграции LLM, модули M09–M11 можно проходить по [быстрому входу](course/fast-track-llm.md): сначала домашняя работа модуля, затем уроки только по пунктам рубрики, оценённым ниже 2.

Всего 103 урока; следуй порядку оглавления, поскольку восстановительные уроки с новыми ID вставлены перед зависимыми темами. Открой его обзор, прочитай урок, попробуй численный пример, сделай свою работу в submissions, затем открой решения. Интерактивные опыты встроены в связанные уроки и доступны из обзоров модулей. Нажми на рисунок, чтобы увеличить его; ответы раскрываются отдельными разделами. Для запуска проверяемого примера:

```powershell
Set-Location C:\projects\ml-llm-course
.\.venv\Scripts\python.exe labs\M03\demo.py
```

Замени M03 на нужный модуль и прочитай его labs/Mxx/README.md. Эталонная лабораторная показывает ожидаемое поведение; запуск готового demo не заменяет самостоятельную реализацию. Результаты сохраняются в artifacts. Подробности LLM и речи, первая загрузка моделей и ограничения описаны в соответствующих модулях.

[Запуск эталонного голосового тренажёра](projects/interview_trainer/README.md). Для всего нового практического комплекта:

```powershell
.\.venv\Scripts\python.exe tools\run_labs.py
```

Первоначальный ориентир нагрузки: 400–600 часов вместе с практикой и собственным проектом, около 4–7 месяцев при 20–25 часах в неделю. Это оценка для планирования, а не обещанный срок; заменяй её измеренным временем из журнала. Часть математических тем может потребовать дополнительных дней.


## Что изменилось после аудита

Добавлены 18 уроков: математические предпосылки, настоящий классификатор и смешанный pipeline, полный Transformer-блок, измерение float32/int8, русский диагностический RAG, парное оценивание реальных ответов, настоящий SFT, HTTP-нагрузка, модельный planner, потоковая речь и самостоятельный итоговый продукт. Для всех модулей есть отдельные стартеры и проверки. Повторные задачи B/C имеют собственные условия и ключи.

[Правила зачёта](course/assessment.md) требуют одновременно корректного результата, понимания и нового самостоятельного решения. [Контрольные точки](course/checkpoints.md) помогают сокращать знакомое чтение и возвращаться к конкретному пробелу. Плановые 226 часов уроков и 82–164 часа модульных работ учитываются отдельно от пилота, установки и повторений; 400–600 часов всего остаются начальной гипотезой, которую нужно заменить твоими измерениями.

Учебные модели могут не пройти порог качества. Сохранённые неудачные эксперименты и отрицательное решение о выпуске — часть инженерной практики. [Разбор обратной связи](course/feedback-case-study.md) показывает, почему корректный JSON и точная цитата не гарантируют полезности. [Проверка исправлений A01–A28](quality/audit-resolution-1.1.0.md) перечисляет изменения и свидетельства.
