# Персональный курс ML и LLM — версия 0.1.0

[Открыть курс в Pages](https://chatgpt.com/space/page_490c579aa2388191be5ce4e3ef598a23) · [Диагностика](https://chatgpt.com/space/page_2cd08dbb505c8191881da74e47eed53d) · [Прогресс](https://chatgpt.com/space/page_8216aadf28ec8191be320051183cf8b2)

Это репозиторий технических материалов персонального русскоязычного курса. Теория, задания, словарь, разборы и основной журнал обучения хранятся в Pages. Здесь находятся исполняемый код, данные, ноутбуки, проверенные зависимости и технические проверки.

## Что выпущено

- Полная программа M00–M16: **17 модулей, 85 уроков, 51 проверяемый результат**, предпосылки и критерии. Страницы модулей содержат программу и вводные черновики, не полный комплект каждого модуля.
- Готовый двухнедельный пилот P01–P10: **10 авторских уроков**, входная диагностика, практика, самостоятельные задания, подсказки, эталоны, повторные и отложенные проверки.
- **10 рабочих ноутбуков и 10 отдельных решений**. Рабочие ноутбуки содержат исполняемые примеры и места для собственной работы.
- Два начальных синтетических набора для будущего тренажёра: 8 HR-случаев и 12 backend-случаев с раздельными рубриками.
- Правила наставника и продолжения в другом чате; начальный журнал без вымышленных результатов.

Учебный пилот ещё не проведён. Подготовка полного содержимого остальных модулей и эталонного голосового продукта следует после пилота и корректировки программы. Полный курс пока **не выпущен**. Технический запуск не подтверждает освоение темы или готовность к грейду middle.

## Начать обучение

1. Выполнить [диагностику](https://chatgpt.com/space/page_2cd08dbb505c8191881da74e47eed53d) до чтения решений. Ориентир 40–60 минут; незнакомое можно обозначить прямо.
2. Сохранить ответы и код в `submissions/D00/` или передать текст в чат. Указать фактическое время и использованные подсказки.
3. Передать работу наставнику; после выбора корректирующих упражнений открыть [P01](https://chatgpt.com/space/page_970b6d8bf8488191835791902181d8e2).
4. Работать в копии ноутбука внутри `submissions/`, сохраняя исходник задания.

Начальный темп — пять основных дней по 4–5 часов в неделю. Оценку нагрузки уточняем по фактическим занятиям. Если предпосылка не освоена, зависимое занятие сдвигается.

## Окружение и запуск

Проверенная конфигурация пилота: Windows x64, Python **3.11.9**, CPU. Видеокарта и платные сервисы не нужны. Установка пакетов требует сети; после установки код пилота использует локальные данные.

Окружение `.venv` уже подготовлено. Из PowerShell:

```powershell
Set-Location C:\projects\ml-llm-course
.\.venv\Scripts\python.exe -m jupyterlab
```

В Jupyter открыть `notebooks/pilot/P01.ipynb`. Выбирать ядро Python этого окружения. Ноутбуки находят корень курса при запуске из вложенной папки, включая `submissions`. Ядро глобально не устанавливается.

Для установки из чистого окружения:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\bootstrap.ps1
```

Для отдельного проверочного окружения:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\bootstrap.ps1 -Environment .venv-verify
```

`ExecutionPolicy Bypass` применяется только к указанному процессу, без изменения постоянной политики Windows. Скрипт использует `py -3.11`, устанавливает закреплённые пакеты из `requirements.lock.txt` и локальный пакет курса. Зафиксированные зависимости проверены именно на Windows/Python 3.11; перенос на другую ОС или Python требует отдельной проверки. `requirements.in` описывает верхнеуровневые потребности, lock — конкретный проверенный набор.

## Техническая проверка

Полный набор проверок текущего выпуска:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\verify.ps1
```

Отдельные команды:

```powershell
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools\validate_course.py --require-pages
.\.venv\Scripts\python.exe tools\run_notebooks.py --kind all --html
```

Только одно занятие: `tools\run_notebooks.py --kind starter --lesson P03`.

Выполненные копии и HTML сохраняются в `artifacts/executed/`, графики — в `artifacts/figures/`, технический отчёт — в `artifacts/notebook-validation.json`. Исходники не перезаписываются. При выборочном запуске отчёт относится только к выбранным файлам. Для проверки всего выпуска нужен `--kind all`.

Автоматический запуск рабочих ноутбуков исполняет примеры. Он **не проверяет незаполненный ответ ученика**. Для отдельных реализаций есть вспомогательная проверка:

```powershell
.\.venv\Scripts\python.exe tools\check_submission.py submissions\my_solution.py --task mse
```

Ожидаются функции `mse(y_true, y_pred)`, `linear_gradient(x, y, w, b)` или `predict_payload(payload)` соответственно. Градиент возвращает пару `(dw, db)`; API — словарь `prediction` и `model_version`. Ошибочные численные входы отклоняются через `ValueError`. Код файла исполняется локально, поэтому команда предназначена для своей работы в этом курсе. Смысл объяснения, перенос и самостоятельность оценивает наставник по реальной попытке.

## Где находятся данные и состояние

| Материал | Основной источник |
| --- | --- |
| Теория, словарь, задания и рубрики | Pages |
| Действительный прогресс и разборы | [Страница прогресса](https://chatgpt.com/space/page_8216aadf28ec8191be320051183cf8b2) |
| Программа, идентификаторы и зависимости | `curriculum.json` |
| Связи страниц, версий и технических материалов | `course-manifest.json` |
| Технические входы для сборки manifest | `metadata/` |
| Код, исходные ноутбуки и решения | `src/`, `notebooks/`, `solutions/` |
| Данные и происхождение | `data/pilot/`, `data/interview/` |
| Работы ученика | `submissions/`, локально, исключены из Git |
| Начальное состояние и формат записи попытки | `progress/` |
| Подтверждение проверки выпуска | `quality/release-0.1.0.json` |

`progress/pilot-status.json` — начальный технический снимок. Он не заменяет журнал в Pages и не обновляется независимо от него. `.authoring/` — временные файлы подготовки публикации; после публикации они не являются вторым редактируемым учебником и не входят в Git.

`course-manifest.json` генерируется командой `python tools/build_manifest.py` из программы и технических метаданных. Метаданные страниц обновляются только после фактической публикации и чтения сохранённого результата.

## Передача следующему наставнику

Открой [инструкцию наставника](https://chatgpt.com/space/page_096411cdf888819181b2b1ffd15e2a72) и страницу прогресса, затем `AGENTS.md` и manifest. Возьми последнюю попытку, назначенную повторную/отложенную проверку и следующую тему. Не повторяй всю диагностику без наблюдаемой причины.

В конце занятия запиши: ID/версию задания, ссылку или путь работы, время, помощь, конкретные подтверждённые умения, ошибки, обратную связь, исправление и следующую проверку. Полученная подсказка меняет условия следующей самостоятельной проверки. Не присваивай статус по факту открытия урока или выполнения эталона.
