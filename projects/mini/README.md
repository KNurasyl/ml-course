# Мини-проекты маршрута 2.0

Один проект на уровень, все на данных одной вымышленной компании (`data/company/`). Работа ученика — в `submissions/MPx/` (не попадает в git). Тьютор делит проект на занятия по 30–45 минут; `check.py` проекта сверяет структуру и пересчитывает числа, оценку не ставит.

| ID | Уровень | Папка | Статус материалов |
| --- | --- | --- | --- |
| MP0 | 0 | запуск по `labs/M09/README.md` (M09-L07X) | готов |
| MP1 | 1 | [MP1-model-passport](MP1-model-passport/README.md) | готов (R07) |
| MP2 | 2 | [MP2-eval-suite](MP2-eval-suite/README.md) | готов (R07) |
| MP3 | 3 | [MP3-support-operator](MP3-support-operator/README.md) | готов (R07) |
| MP4–MP6 | 4–6 | — | пишутся за уровень до ученика (R20) |

Общие функции — `common.py`: загрузка базы знаний и запросов, каппа Коэна, печать отчёта проверки.
