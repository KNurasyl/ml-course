# Работа над персональным курсом

## Состояние и источники

Сначала прочитать README.md, course-manifest.json и progress/progress.md. По новому указанию пользователя весь актуальный курс и прогресс хранятся локально. Каноническая теория — Markdown в course/, ключи — solutions/pilot/answer-key.md и solutions/modules/. START_HERE.html — генерируемая копия для чтения, пересобирается tools/build_reader.py. Не требовать доступ к Pages, чату или проверку наставника для продолжения обучения. Помощь и независимая проверка доступны по желанию ученика.

Ученик: разработчик JS/TS/Python/Go, восстанавливает вузовскую математику, русский язык, 4–5 часов в день. Обязательная практика бесплатная, локальная, CPU или 4 ГБ VRAM. По последнему указанию пользователя полный курс создаётся сейчас для самостоятельного прохождения; реальный учебный пилот и персональная калибровка учитываются отдельно и не блокируют доступ к материалам.

## Честность состояния

Не отмечать навык освоенным по факту запуска эталонного кода. Не фабриковать ответы, длительность занятий, результаты пилота или карьерную готовность. Материалы, результаты ученика и трудоустройство имеют отдельные состояния.

Ранее опубликованные страницы — исторические копии. Их адреса оставлены только в metadata/source-pages.json как происхождение. Не использовать их вместо локального актуального текста. `.authoring` содержит архив подготовки: старые генераторы версии 0.1.0 повторно не запускать, они перезапишут новые самостоятельные материалы.

## Педагогика

Каждому результату нужны объяснение, практика и самостоятельная проверка. После подсказки проверять новый случай. Критические ошибки эксперимента не компенсировать оформлением. Формула должна сопровождаться смыслом величин и численным примером. Разрешать AI по режиму конкретного задания.

## Проверка

После изменения кода запускать соответствующие pytest и затронутые ноутбуки. После изменения Markdown пересобрать START_HERE.html, затем course-manifest.json и проверить tools/validate_course.py --require-local. Полную проверку выполнять перед выпуском. Проверки не присваивают ученику оценку автоматически. Самопроверку отмечать отдельно от внешнего подтверждения навыка. Не устанавливать зависимости глобально, не публиковать репозиторий и не скачивать крупные модели без отдельной необходимости.
