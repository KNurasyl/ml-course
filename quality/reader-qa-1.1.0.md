# Проверка учебника 1.1.0: план и свидетельства

Этот файл задаёт проверяемые пользовательские действия. Фактический результат сохраняется в artifacts/reader-v2-qa.json; до выполнения сценарий не считается пройденным.

| Поведение | Состояния для проверки | Свидетельство |
|---|---|---|
| Новые уроки доступны в педагогическом порядке | M04-L06 перед M04-L01; все дополнительные L06+ доступны через оглавление | DOM-порядок и переходы по реальным ссылкам |
| Открывается только нужное решение | Переход из урока, соседний ответ остаётся закрытым, ручное закрытие/открытие | Число и ID открытых details |
| Критерии видны до ответа | Урок без открытых подсказок | Снимок и DOM-содержание критериев |
| Рисунок читается на телефоне | 390×844, открыть, исходный размер, вернуть fit, закрыть Escape | Размер рисунка и снимки обоих состояний |
| Интерактив встроен в урок | M08-L03, изменённые значения, iframe без сети | Числа, визуальное состояние и отсутствие сетевых запросов |
| Attention: Q/K/V, маска и ось | Изменить только V, затем Q; включить mask; включить неверную ось | Неизменность A при V, изменение O, нулевое будущее, нарушение сумм |
| Прогноз и сброс | Пустой ввод, неверное число, верное число, reset | Сообщение и восстановленные значения |
| Поиск и клавиатура | Русский термин, пустой результат, очистка, Escape | Видимые разделы и фокус |

Дополнительные отрицательные случаи: ссылка на один ключ не раскрывает все решения; неправильная ось softmax может иметь верные shapes, но должна быть явно обозначена. Техническая проверка интерфейса не подтверждает усвоение темы учеником.


Проверка выполнена в Edge при 1440×1000 и 390×844 с offline-контекстом. Все 15 проверенных сценариев в reader-v2-qa.json пройдены; сетевых запросов нет. Численные состояния attention и открытие единственного ключа проверены через настоящие элементы интерфейса, не только снимком. Мобильные снимки сделаны после завершения анимации оглавления. Дополнительные регрессии порядка и deep-link находятся в tests/test_reader_v2.py.
