# Замер железа ноутбука ученика (R06)

Отчёт: [`baseline.json`](baseline.json), замер 18.11.2026. Инструмент: `tools/hardware_baseline.py` и `tools/hardware_4bit.py`.

Машина: Intel Core i7-11800H (8 ядер, 16 потоков), 32 ГБ RAM, NVIDIA GeForce RTX 3050 Ti Laptop (4096 МиБ), драйвер 621.24, Windows 11. llama.cpp b11803: CPU-сборка из M09-L07X и официальная CUDA 13.4 сборка того же релиза (`runtime/llama.cpp/b11803-cuda`, SHA-256 проверены). Промпты и настройки — из `labs/M09/llama_serving.py` (T30): шесть запросов, жадное декодирование, до 64 новых токенов, размышления Qwen3.5 выключены. Значения — медианы по запросам после одного прогревочного запроса. CPU — 8 потоков.

Перед загрузкой свободно 3243–3295 МиБ из 4095: остальное занимает рабочий стол. Пик по всей карте во время запросов (`vram_card_peak_mib`) — 3411 МиБ на 4k и 3695 МиБ на 16k.

**4-битная загрузка в PyTorch** (`.venv-gpu`: torch 2.15.0+cu132, bitsandbytes 0.50.2, transformers 4.57.6, без WSL2): Qwen2.5-0.5B-Instruct в NF4 — 168 слоёв `Linear4bit`, веса 430 МиБ против 942 МиБ во float16, пик CUDA 520 против 960 МиБ, 16,4 против 20,1 токена в секунду.

## Гипотезы плана (раздел 8)

| Гипотеза | Итог | Основание |
| --- | --- | --- |
| 4B в Q4 целиком помещается в 4 ГБ видеопамяти с рабочим контекстом | подтверждена для 4k и 8k | 33/33 слоя на GPU; 2991 МиБ при 8k из 3243 свободных. 16k требует 3255 МиБ — без запаса при открытом рабочем столе, работает на грани |
| 4-битная загрузка (bitsandbytes) работает в Windows без WSL2 | подтверждена | см. выше |
| QLoRA до 1,5B возможна, 3–4B — на грани | не проверялась | R06 проверяет загрузку и генерацию, обучение — M12-L11X (R21) |

## Выбор модели для занятий

`session_model` в `course/route-v2.yaml`: **Qwen3.5-4B Q4_K_M на GPU, контекст 8192**. Она в 8 раз быстрее той же модели на CPU (47 против 5,9 токена в секунду), до первого токена 0,14 с. По качеству в T51 (`quality/model-comparison/report.md`) 4B выдаёт правильный JSON по инструкции, а 0.5B — только с ограниченным выводом; порог допуска M11 не прошла ни одна из них, так что выбор сделан по скорости и формату, а не по доказанному качеству ответов. Запасной вариант на CPU (И7) — та же 4B на CPU для заданий без спешки или 0.5B на CPU (42 токена в секунду). Тесты курса по-прежнему используют 0.5B (И9).

Ограничения замера: один прогон, короткие запросы (до 30 токенов на входе), один параллельный слот. Длинный контекст и параллельные запросы измеряются в MP1 и MP6. Измеренное здесь относится к этому ноутбуку и не переносится на сервер без расчёта.

## Как повторить

```powershell
.\.venv\Scripts\python.exe tools\hardware_baseline.py fetch-cuda
.\.venv\Scripts\python.exe tools\hardware_baseline.py bench
```

`bench` без `.venv-gpu` пропускает 4-битную проверку со статусом `gpu_env_missing`; как создать окружение — в конце `requirements-optional.in`.
