Тёплый графит вместо чисто чёрного: меньше ореолов у текста, глаз не «плывёт» между абзацами. Текст слегка тёплый (#e7e5de), не белый. Диагностировать русский RAG по трассе ошибки

После урока: отличить потерю нужного документа, потерю условия при разбиении, устаревшую версию и вопрос без ответа; выбрать исправление по наблюдению.

Почему хороший Recall может скрывать плохой контекст

Допустим, документ говорит: «Индекс может ускорить запрос. Он не гарантирует ускорения выборки почти всей таблицы». Поиск нашёл нужный документ — recall по document_id равен единице. Но в переданный генератору фрагмент попало только первое предложение. Генератор потерял условие, хотя документная метрика этого не заметила.

MRR = (1/N) · Σ 1/rank_i, rank_i = позиция первого релевантного chunk, 0 если не найден

Практика с поддержкой

Запиши ожидаемый вывод до запуска; объясни расхождение.

from labs.M10.diagnostic_ru import trace
report = trace(query="ускоряет ли индекс выборку всей таблицы", k=3)
# ожидаю: doc_recall == 1.0, chunk_sufficient == False
assert report.doc_recall == 1.0 and not report.chunk_sufficient

Число документов в контексте k. Из шести кандидатов релевантны три. Где precision и recall разойдутся?

Правила оформления

Поверхности: три уровня, не один

Страница → панель (боковая, подсказки, опыты) → карточка (рисунки, таблицы). Каждый уровень на 3–4% светлее. Код и формулы наоборот темнее страницы: взгляд их находит без рамок. Тени не используются — на тёмном они не читаются, глубину даёт яркость.

Цвет кодирует тип блока

Синий — навигация и ссылки. Бирюзовый — всё, где ученик действует: опыт, ответ, активная задача. Янтарный — подсказки, фокус, выделение поиска. Оранжевый и красный — только статусы и критические ошибки. Один блок = один акцент.

Рисунки и схемы

SVG: вместо констант INK='#182b3a' генератор пишет fill="var(--ink)", белую подложку убирает — рисунок лежит на карточке. Mermaid переходит на theme:'base' с themeVariables из тех же токенов. PNG из matplotlib перегенерируются в две версии через plt.style и вставляются через <picture> с prefers-color-scheme; пока не перегенерированы — лежат на светлой карточке с рамкой, без инверсии фильтром.

Чего не делать

Чисто чёрный фон и белый текст

#000 и #fff дают контраст 21:1 — слишком резко для 4 часов чтения, буквы «светятся». Графит и слегка тёплый текст читаются дольше без усталости.

Инвертировать рисунки фильтром

filter:invert() превращает синий в оранжевый и ломает смысл цветовой легенды. Либо перегенерация, либо светлая карточка с рамкой.

Переносить светлые акценты как есть

Старый синий #245bba на тёмном — 2,8:1, старый бирюзовый #087e82 — 3,6:1. Оба ниже порога AA для текста.

Веб-шрифты

Учебник офлайн. Google Fonts не загрузится; встраивать 400 КБ шрифтов в HTML можно, но Segoe UI на Windows уже хороша для кириллицы. Если захочется характерный шрифт — только локальный woff2 по OFL-лицензии (Golos Text, IBM Plex Sans).

Контрасты посчитаны по формуле WCAG 2.1 для пар «текст — фон страницы». Макет не является сборкой учебника; это образец для правок в tools/reader.css.
