Почему хороший Recall может скрывать плохой контекст

Допустим, документ говорит: «Индекс может ускорить запрос. Он не гарантирует ускорения выборки почти всей таблицы». Поиск нашёл нужный документ — recall по document_id равен единице. Но в переданный генератору фрагмент попало только первое предложение. Генератор потерял условие, хотя документная метрика этого не заметила.

Значит, нужны разные единицы наблюдения. Документ — исходный материал; chunk — конкретный фрагмент; утверждение — то, что нужно подтвердить. В лабораторной отдельно сохраняются ранги уникальных документов и три реально выбранных chunks. Повторные chunks одного документа схлопываются для документной метрики, но остаются видны в контексте: именно они занимают его бюджет.

MRR = (1/N) · Σ 1/rank_i, rank_i = позиция первого релевантного chunk, 0 если не найден
from labs.M10.diagnostic_ru import trace
report = trace(query="ускоряет ли индекс выборку всей таблицы", k=3)
# ожидаю: doc_recall == 1.0, chunk_sufficient == False  →  Il1 O0 {} []
assert report.doc_recall == 1.0 and not report.chunk_sufficient

Сначала отдели единицы наблюдения: документ, chunk, утверждение. Метрика считается для одной из них.

Проверка на сложных местах

Кириллица, где шрифты ломаются

бвджзлфцщъыьэюя Дд Лл Фф

Смотри на «б», «д», «л», «ф»: у адаптированных латинских шрифтов они часто неровные по ширине и высоте.

Код: похожие символы

Il1| O0o {}[]() -> => != <=

Моноширинный должен различать I/l/1 и O/0 без усилий. Cascadia и JetBrains Mono — да; Consolas — хуже с l/1.

Формулы и смешанный текст

Градиент MSE: ∂L/∂w = (2/n)·Σ eᵢxᵢ, шаг η = 0.25, recall@3 = 0.95, Recall@N до reranking.

Латинские термины внутри русской фразы не должны «выпрыгивать» по весу и высоте.

Как это попадёт в офлайн-учебник

ШагЧтоДетали
F1Скачать woff2 один разИз репозиториев гарнитур (OFL). Подмножество latin + cyrillic, начертания 400/500/700 для текста и 400/600 для моно. Файлы в tools/fonts/, в git.
F2Встроить в сборкуbuild_reader.py вставляет @font-face с src:url(data:font/woff2;base64,…) и font-display:swap. HTML вырастет на 190–300 КБ. Запасной стек: Segoe UI / Consolas.
F3Опыты и рисункиvisual-style.css и генератор SVG берут тот же стек; в SVG шрифт встроить нельзя — там остаётся системный запасной, визуально близкий.
F4Проверкаcheck_reader_design.cjs: нет внешних запросов, шрифт загружен (document.fonts), скриншоты 1440 и 390.

Около одного дня работы агента вместе с D1 (токены темы). Лицензия OFL разрешает встраивание и распространение вместе с учебником.

Веса файлов — оценка для подмножества latin + cyrillic в woff2; точные цифры появятся после F1. Шрифты на этой странице загружены из Google Fonts только для демонстрации.
