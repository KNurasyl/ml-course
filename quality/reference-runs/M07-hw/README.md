# Сохранённый эталонный прогон M07-HW01

Копия комплекта, который [hw_reference.py](../../../solutions/exercises/M07/hw_reference.py) записывает в `artifacts/M07/hw-reference/`: seed=23, noise=0,30, split 600/200/200, checkpoint эпохи 115. Папка `artifacts/` генерируется и не хранится в git, поэтому ключ [M07](../../../solutions/modules/M07.md) ссылается на эту копию — так отчёт открывается и в свежем клоне.

Копия снята 4 ноября 2026 года с прогона на окружении из `requirements.lock.txt` (Python 3.11.9, PyTorch 2.15.0+cpu, CPU) и перенесена побайтово. Файлы не содержат меток времени. `hw-report.json` побайтово совпадает со снимком выпуска 1.1.0 `quality/measurements-1.1.0/M07-hw-reference-hw-report.json`, то есть прогон воспроизводим.

| Файл | Содержимое |
| --- | --- |
| `hw-report.md` | Связный разбор: точность MLP и логистической регрессии, две реальные ошибки, численная проверка градиента |
| `hw-report.json` | Полные неокруглённые значения, индексы соседей и условия запуска |
| `loss-and-errors.png` | Кривые loss и ошибки на test |
| `model.pt`, `release.json` | Выбранный checkpoint и параметры восстановления |
| `split.json`, `history.json`, `report.json`, `training.log` | Разбиение, история обучения и итоговые метрики |

Свой запуск ученик выполняет сам; результат пишется в `artifacts/M07/hw-reference/`, а не сюда. Эту папку не перезаписывать: это сохранённое свидетельство, а не рабочая копия.
