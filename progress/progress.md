## Обновление копии для чтения

После изменения журнала или уроков из папки курса выполни:

```powershell
.\.venv\Scripts\python.exe tools\build_reader.py
```

Затем обнови START_HERE.html в браузере. Markdown-файл остаётся первичным; создавать отдельную редактируемую копию прогресса в HTML не нужно.
