# M15: самостоятельный компонент

Версия 1.1.0. Обработай последовательность begin/receive/cancel/play. begin задаёт возрастающий номер эпохи и очищает очередь; cancel увеличивает эпоху и очищает очередь; receive принимает только активную эпоху; play берёт первый разрешённый фрагмент. Верни список действительно допущенных к воспроизведению payload. Аудио здесь не исполняется.

Скопируй starter.py в submissions/M15/my_solution.py, реализуй функцию и сохрани объяснение решения. Не открывай готовый solution до первой попытки.

```powershell
.\.venv\Scripts\python.exe exercises\M15\check.py submissions\M15\my_solution.py
```

Проверка возвращает behavior_passed; самостоятельность и понимание она не определяет. При ошибке сократи свой пример и объясни нарушенный контракт. Стартовый файл намеренно не проходит проверку.

После попытки: [полное решение](../../solutions/exercises/M15/solution.py). Проверка ключа и чувствительности к намеренному дефекту:

```powershell
.\.venv\Scripts\python.exe exercises\M15\check.py solutions\exercises\M15\solution.py --self-test
```

Новый пример после просмотра решения приведён в соответствующем новом уроке и ключе модуля. Нельзя считать повторный запуск этого же ключа самостоятельным результатом.
