# M13: самостоятельный компонент

Версия 1.1.0. Выбери целый релиз только после трёх независимых проверок schema/canary/regressions. Все значения — именно bool True; отсутствие проверки и несовместимый schema оставляют previous. Не изменяй словари. Это компонент приёмки; HTTP-измерения выполняются отдельно.

Скопируй starter.py в submissions/M13/my_solution.py, реализуй функцию и сохрани объяснение решения. Не открывай готовый solution до первой попытки.

```powershell
.\.venv\Scripts\python.exe exercises\M13\check.py submissions\M13\my_solution.py
```

Проверка возвращает behavior_passed; самостоятельность и понимание она не определяет. При ошибке сократи свой пример и объясни нарушенный контракт. Стартовый файл намеренно не проходит проверку.

После попытки: [полное решение](../../solutions/exercises/M13/solution.py). Проверка ключа и чувствительности к намеренному дефекту:

```powershell
.\.venv\Scripts\python.exe exercises\M13\check.py solutions\exercises\M13\solution.py --self-test
```

Новый пример после просмотра решения приведён в соответствующем новом уроке и ключе модуля. Нельзя считать повторный запуск этого же ключа самостоятельным результатом.
