# M03: собственная реализация и проверка

Версия 1.1.0. Эти файлы — заготовка задания, а не готовое решение. Скопируй starter.py в submissions/M03/solution.py. Реализуй контракты docstring; исходную заготовку сохраняй неизменной. Пустой starter намеренно не проходит проверку и не является сломанной лабораторной.

Из корня курса:

```powershell
.\.venv\Scripts\python.exe exercises\M03\check.py submissions\M03\solution.py
```

Checker загружает **твой** Python-файл и проверяет его поведение на фиксированных случаях, включая ошибки. Не запускай чужой непроверенный файл. Exit code 0 означает прохождение перечисленных технических проверок; он не оценивает объяснение и самостоятельность. Сохрани JSON и собственное объяснение рядом с работой. При провале посмотри вход из check.py, воспроизведи его вручную и исправь причину.

После собственной попытки можно сравнить с [эталоном](../../solutions/exercises/M03/solution.py). Проверка эталона той же командой с соответствующим путём подтверждает, что контракт выполним. После полного разбора реши вариант B, а через 3–7 дней вариант C из [модуля](../../course/modules/M03.md). Ключи разных вариантов находятся в [решениях модуля](../../solutions/modules/M03.md).

Окружение: существующий Python 3.11, requirements.lock.txt курса, CPU. Платных API и GPU нет. Все маленькие данные авторские. Для перехода дальше обязательны все предметные критерии, отсутствие критических ошибок и самостоятельное объяснение нового случая.
