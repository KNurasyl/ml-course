# M03: собственная реализация и проверка

Версия 1.1.0. Эти файлы — заготовка задания, а не готовое решение. Скопируй starter.py в submissions/M03/solution.py. Реализуй контракты docstring; исходную заготовку сохраняй неизменной. Пустой starter намеренно не проходит проверку и не является сломанной лабораторной.

Из корня курса:

```powershell
.\.venv\Scripts\python.exe exercises\M03\check.py submissions\M03\solution.py
```

Checker загружает **твой** Python-файл и проверяет его поведение на фиксированных случаях, включая ошибки. Не запускай чужой непроверенный файл. Exit code 0 означает прохождение перечисленных технических проверок; он не оценивает объяснение и самостоятельность. Сохрани JSON и собственное объяснение рядом с работой. При провале посмотри вход из check.py, воспроизведи его вручную и исправь причину.

После собственной попытки можно сравнить с [эталоном](../../solutions/exercises/M03/solution.py). Проверка эталона той же командой с соответствующим путём подтверждает, что контракт выполним. После полного разбора реши вариант B, а через 3–7 дней вариант C из [модуля](../../course/modules/M03.md). Ключи разных вариантов находятся в [решениях модуля](../../solutions/modules/M03.md).

Окружение: существующий Python 3.11, requirements.lock.txt курса, CPU. Платных API и GPU нет. Все маленькие данные авторские. Для перехода дальше обязательны все предметные критерии, отсутствие критических ошибок и самостоятельное объяснение нового случая.

## Дополнительные упражнения (версия 1.2.0)

Ещё два контракта по урокам M03-L01, M03-L02, M03-L04 и M03-L05. Скопируй стартер в `submissions/M03/` под тем же именем, реализуй функции и проверь:

```powershell
.\.venv\Scripts\python.exe exercises\M03\check_ex02.py submissions\M03\ex02_derivatives.py
.\.venv\Scripts\python.exe exercises\M03\check_ex03.py submissions\M03\ex03_steps.py
```

| Упражнение | Уроки | Что реализовать |
| --- | --- | --- |
| `ex02_derivatives.py` | M03-L01, M03-L02 | Прямую и центральную разности и градиент одного примера по цепному правилу |
| `ex03_steps.py` | M03-L04, M03-L05 | Траекторию градиентного спуска, границу устойчивого шага для c(w − m)² и оптимум с L2-штрафом |

Как устроена проверка. Числа сравниваются с допуском. Кроме фиксированных примеров проверка берёт случайные входы и проверяет свойства: центральная разность точна для любой квадратичной функции, при x = 0 производная по w равна нулю, при шаге ниже границы расстояние до минимума убывает, а выше — растёт. Градиент сверяется с конечной разностью, которую проверка считает сама. `--seed 7` даёт новый набор случайных входов. Часть случаев скрыта в `tests/hidden/` — по правилам самопроверки их не открывают.

Зелёная проверка подтверждает поведение функций, но не понимание: после неё объясни в журнале, почему множитель 1 − 2cη решает судьбу спуска и почему L2-оптимум ближе к нулю, чем оптимум без штрафа. Эталоны — [ex02](../../solutions/exercises/M03/ex02_derivatives.py), [ex03](../../solutions/exercises/M03/ex03_steps.py); открывай их только после своей попытки.
