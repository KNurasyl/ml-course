# M07: самостоятельный validation-pass

Версия 1.1.0. Скопируй starter.py в submissions/M07/solution.py. Реализуй validation_loss без изменения весов, без градиентов и с восстановлением исходного train/eval состояния. Dropout должен быть выключен во время измерения. Верни Python float.

Сначала объясни, почему model.eval() и отсутствие градиентов нужны одновременно. Одно не заменяет другое. Первый запуск checker выполняй после собственной попытки:

```powershell
.\.venv\Scripts\python.exe exercises\M07\check.py submissions\M07\solution.py
```

Проверяются параметры, gradients, dropout, повторный вызов и сохранение режима. Результат не присваивает самостоятельность: приложи своё объяснение и объём помощи.

Вариант B: модель изначально eval, после проверки должна остаться eval. Вариант C через неделю: validation бросает исключение из-за неверной формы y; исходный режим всё равно должен восстановиться. Эталон находится в solutions/exercises/M07/solution.py и в ключе M07. Не открывай его до сохранения своей попытки.
