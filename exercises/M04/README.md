# M04: собственная реализация и проверка

Версия 1.1.0. Эти файлы — заготовка задания, а не готовое решение. Скопируй starter.py в submissions/M04/solution.py. Реализуй контракты docstring; исходную заготовку сохраняй неизменной. Пустой starter намеренно не проходит проверку и не является сломанной лабораторной.

Из корня курса:

```powershell
.\.venv\Scripts\python.exe exercises\M04\check.py submissions\M04\solution.py
```

Checker загружает **твой** Python-файл и проверяет его поведение на фиксированных случаях, включая ошибки. Не запускай чужой непроверенный файл. Exit code 0 означает прохождение перечисленных технических проверок; он не оценивает объяснение и самостоятельность. Сохрани JSON и собственное объяснение рядом с работой. При провале посмотри вход из check.py, воспроизведи его вручную и исправь причину.

После собственной попытки можно сравнить с [эталоном](../../solutions/exercises/M04/solution.py). Проверка эталона той же командой с соответствующим путём подтверждает, что контракт выполним. После полного разбора реши вариант B, а через 3–7 дней вариант C из [модуля](../../course/modules/M04.md). Ключи разных вариантов находятся в [решениях модуля](../../solutions/modules/M04.md).

Окружение: существующий Python 3.11, requirements.lock.txt курса, CPU. Платных API и GPU нет. Все маленькие данные авторские. Для перехода дальше обязательны все предметные критерии, отсутствие критических ошибок и самостоятельное объяснение нового случая.

## Дополнительные упражнения (версия 1.2.0)

Ещё два контракта по урокам M04-L02, M04-L03, M04-L05 и M04-L06. Скопируй стартер в `submissions/M04/` под тем же именем, реализуй функции и проверь:

```powershell
.\.venv\Scripts\python.exe exercises\M04\check_ex02.py submissions\M04\ex02_estimates.py
.\.venv\Scripts\python.exe exercises\M04\check_ex03.py submissions\M04\ex03_tests.py
```

| Упражнение | Уроки | Что реализовать |
| --- | --- | --- |
| `ex02_estimates.py` | M04-L02, M04-L03 | Среднее, s² с n − 1, s и стандартную ошибку; интервал Уилсона для доли |
| `ex03_tests.py` | M04-L05, M04-L06 | Двусторонний знаковый тест без ничьих и среднюю бинарную log loss с проверкой области определения |

Как устроена проверка. Числа сравниваются с допуском. Случайные входы сверяются с NumPy, SciPy и scikit-learn, которые проверка вызывает сама; ученику эти функции в решении не нужны. Свойства: сдвиг данных не меняет дисперсию, SE равна s/√n, интервал Уилсона лежит в [0, 1], содержит долю и сужается при вчетверо большем n; знаковый тест симметричен и не зависит от ничьих, лишняя победа не увеличивает p-value; замена классов местами не меняет log loss, а при p = 0.5 потеря равна ln 2. Нулевая вероятность случившегося класса должна приводить к ошибке, а не к нулю. `--seed 7` даёт новый набор случайных входов. Часть случаев скрыта в `tests/hidden/` — по правилам самопроверки их не открывают.

Зелёная проверка подтверждает поведение функций, но не понимание: после неё объясни в журнале, почему SE уменьшается с ростом n, а s — нет, и почему уверенная ошибка стоит в log loss так дорого. Эталоны — [ex02](../../solutions/exercises/M04/ex02_estimates.py), [ex03](../../solutions/exercises/M04/ex03_tests.py); открывай их только после своей попытки.
