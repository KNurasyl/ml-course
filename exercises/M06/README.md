# M06-HW01: превратить схему в проверяемый контракт

Скопируй starter.py в submissions/M06-HW01. Реализуй execute по контракту; первой попытке не нужен HTTP. Разбери вручную выпуск A: mean=10,scale=2,weight=3,bias=1 и x=14. Потом проверь изменённый выпуск B с mean=12. Один request не может незаметно сменить результат из-за повторной доставки после релиза.

```powershell
.\.venv\Scripts\python.exe exercises\M06\check.py submissions\M06-HW01\starter.py
```

Добавь схему запроса и отказа: кто владеет cache, сколько живут записи, что произойдёт после перезапуска. Этот учебный словарь не является долговременным хранилищем и не потокобезопасен; переход к конкурентному HTTP и восстановлению выполняется в M13. Результат считается самостоятельным после объяснения без ключа и нового случая.

Вариант B: x=16, новый session, выпуск A. Затем меняется только active release на B, повторяется тот же запрос, а после — новый turn. Вариант C через неделю: другая сессия использует тот же номер turn; покажи, что чужой ответ не возвращается. Также проверь изменение возвращённого словаря: оно не должно портить следующий retry.
