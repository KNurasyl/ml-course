# Происхождение и контракт данных M05

Все три CSV созданы генератором `labs/M05/pipeline.py::make_data` для версии курса 1.1.0. Реальных кандидатов, переписки и стороннего датасета здесь нет. Данные разрешено копировать и изменять для учебных экспериментов; сохраняй пометку о синтетическом происхождении. Они не являются валидированной шкалой оценки людей.

| Файл | Seed | Особое условие |
|---|---:|---|
| hw.csv | 2026 | Группа пересекает границу144; неизвестный track в последнем окне |
| retry.csv | 2027 | Новая цена FN=4 и граница140; пересечение нужно пересчитать |
| delayed.csv | 2028 | Независимый набор для отложенной проверки старого контракта |

В каждом файле 240 сессий. ID строки уникален. Смена user_id в специальном случае намеренно создаёт группу с четырьмя строками; нельзя предполагать, что у любого человека всегда ровно две сессии.

| Поле | Смысл и доступность |
|---|---|
| row_id | Уникальный ID записи, индекс таблицы |
| user_id | Группа сессий, только для разбиения и аудита |
| day | Условный день, только для временного разбиения |
| experience_years | Доступный числовой признак; пропуск допустим |
| answer_words | Доступный числовой признак; пропуск допустим |
| track | Доступная категория; новые значения возможны |
| review_score_after | Появляется после оценки; запрещённый признак из будущего |
| is_ready | Авторская бинарная учебная метка; не пригодность к найму |

Генерация: линейный score от опыта, длины и направления → сигмоида → случайный бинарный исход. Поэтому одинаковые признаки не обязаны иметь одинаковую метку. Дополнительный будущий столбец специально связан с меткой. Его исключение нужно обосновать моментом доступности, а не низкой корреляцией.

Хеши файлов записываются в отчёт полного ключа; зафиксированные версии находятся в provenance.json. При изменении CSV создавай новую версию набора и не сравнивай результаты как будто данные прежние. Наборы B/C следует открывать после исходной самостоятельной работы.
