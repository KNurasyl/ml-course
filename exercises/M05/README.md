# M05: собственная реализация и проверка

Версия 1.1.0. Эти файлы — заготовка задания, а не готовое решение. Скопируй starter.py в submissions/M05/solution.py. Реализуй контракты docstring; исходную заготовку сохраняй неизменной. Пустой starter намеренно не проходит проверку и не является сломанной лабораторной.

Входные таблицы: [hw.csv](data/hw.csv), [retry.csv](data/retry.csv), [delayed.csv](data/delayed.csv). Перед кодом прочитай [словарь полей и происхождение](data/README.md). Сначала `split_records` определяет ID целых групп; затем `build_pipeline(C)` обучается только на train. После выбора C и порога по validation сохраняй решение до расчёта test. `FitAudit` из `labs.M05.pipeline` можно использовать готовым, но split, preprocessing, классификатор и стоимость нужно объяснить и реализовать самостоятельно.

Минимальная последовательность: `pd.read_csv(..., index_col='row_id')` → `split_records` → `pipeline.fit(train, train.is_ready)` → `predict_proba(validation)` → `choose_threshold` → сохранение выбора → один финальный test. Не вызывай fit на объединении частей ради «заполнения всех пропусков».

Полный ключ домашней работы запускается **после попытки**: `.\.venv\Scripts\python.exe solutions\exercises\M05\run_hw.py --variant hw`. Для B/C замени hw на retry/delayed. Это отдельные условия; демонстрационный `labs/M05/pipeline.py` не выдаёт готовый ответ на эту работу. Сопоставь `selection-before-test.json`, `report.json`, артефакт модели и `probabilities.npy` в artifacts/foundation-hw/M05/.

Из корня курса:

```powershell
.\.venv\Scripts\python.exe exercises\M05\check.py submissions\M05\solution.py
```

Checker загружает **твой** Python-файл и проверяет его поведение на фиксированных случаях, включая ошибки. Не запускай чужой непроверенный файл. Exit code 0 означает прохождение перечисленных технических проверок; он не оценивает объяснение и самостоятельность. Сохрани JSON и собственное объяснение рядом с работой. При провале посмотри вход из check.py, воспроизведи его вручную и исправь причину.

После собственной попытки можно сравнить с [эталоном](../../solutions/exercises/M05/solution.py). Проверка эталона той же командой с соответствующим путём подтверждает, что контракт выполним. После полного разбора реши вариант B, а через 3–7 дней вариант C из [модуля](../../course/modules/M05.md). Ключи разных вариантов находятся в [решениях модуля](../../solutions/modules/M05.md).

Окружение: существующий Python 3.11, requirements.lock.txt курса, CPU. Платных API и GPU нет. Все маленькие данные авторские. Для перехода дальше обязательны все предметные критерии, отсутствие критических ошибок и самостоятельное объяснение нового случая.
