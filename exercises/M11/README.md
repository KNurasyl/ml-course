# M11: сравнить две системы по одним случаям

Версия задания 1.1.0. Сначала скопируй `starter.py` в `submissions/M11-HW01/` и реализуй контракт `compare_pairs`. Не открывай решение до сохранения попытки. Запуск из корня курса:

```powershell
.\.venv\Scripts\python.exe exercises\M11\check.py submissions\M11-HW01\starter.py
```

Проверяются порядок строк, пропуски, дубликаты, недопустимые типы и критическая регрессия при росте среднего. Это вычислительная часть: объяснение и независимость отмечаешь отдельно. Проектная часть — [полный протокол M11](../../course/lessons/M11-L06.md).

**Вариант B после разбора:** A: p=2,q=0,r=1; B в другом порядке: r=0,p=2,q=2. Критическая ошибка появилась в p, хотя его балл не изменился. Запиши оба вида регрессии и решение о выпуске. **Вариант C через неделю:** в B отсутствует q. Нельзя считать его нулём или удалять из A; покажи, что сравнение отклонено до вычисления среднего. Затем добавь явно размеченный q=0 и пересчитай.

После собственной попытки: [код решения](../../solutions/exercises/M11/solution.py) и [разбор вариантов](../../solutions/modules/M11.md). Для новой оценки после полного ключа используй C, сохрани полученную помощь и объясни, почему отсутствие оценки отличается от плохой оценки.
