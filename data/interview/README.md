# Учебные наборы интервью

Два независимых по рубрике набора: HR — структура и обоснованность ответа; backend — техническая корректность, аргументация и границы. Все примеры синтетические, созданы для этого курса. Реальных персональных данных нет.

Статус `author_seed_not_human_validated`: это стартовые примеры для разработки и обучения разметке. Они не являются независимо проверенным тестовым набором и не доказывают качество интервьюера. В M11 ученик подготовит отдельно размеченную отложенную выборку. Не подбирать подсказки по её ответам.

Перед автоматизацией провести ручную разметку, обсудить расхождения и уточнить рубрику. Отсутствующие сведения помечать как неизвестные; не достраивать за человека опыт или личные качества.
