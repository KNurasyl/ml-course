# «Лампа и Чайник» — вымышленная компания для мини-проектов

Интернет-магазин бытовой техники в восьми городах Казахстана. Компания, товары, клиенты и обращения придуманы и сгенерированы; совпадения с реальными организациями случайны. Домен `lampa-chainik.test` зарезервирован и никуда не ведёт, телефон вымышленный. Персональных данных нет: клиенты — это `C00001` и город.

Все файлы, кроме `generate.py` и этого README, собирает генератор, и вручную их не правят:

```powershell
.\.venv\Scripts\python.exe data\company\generate.py          # записать заново
.\.venv\Scripts\python.exe data\company\generate.py --check  # сверить файлы с генератором
```

| Файл | Что внутри | Где нужно |
| --- | --- | --- |
| `kb/KB-001.md` … `KB-042.md` | база знаний: доставка по городам, возврат, гарантия по категориям, оплата, установка, бонусы, сервис, поддержка, подбор товара | MP2, MP3 |
| `facts.json` | числа, из которых собрана база знаний (сроки, цены, пороги) — для проверки ответов кодом | MP2, MP3 |
| `products.csv` | 60 товаров: SKU, категория, цена, гарантия | MP4 |
| `customers.csv`, `orders.csv`, `order_items.csv` | 800 клиентов и 3000 заказов за 2026 год | MP4, MP6 |
| `schema.sql` | схема этих таблиц для PostgreSQL | MP4 |
| `tickets.jsonl` | 600 обращений с разметкой: категория (8 видов), номер заказа, SKU, город, срочность | MP5 |
| `operator_requests.jsonl` | 20 запросов оператору с ожидаемыми полями | MP1 |
| `manifest.json` | SHA-256 каждого файла и seed генератора | проверка |

Ограничения синтетики: обращения собраны из 24 шаблонов, поэтому модель на них учится легче, чем на живых текстах; в MP5 это нужно назвать в выводе. Числа в базе знаний правдоподобны, но не взяты у реального магазина.
