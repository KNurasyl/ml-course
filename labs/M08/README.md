# M08 — маленький causal Transformer

```powershell
Set-Location C:\projects\ml-llm-course
.\.venv\Scripts\python.exe labs\M08\demo.py
```

Python 3.11.9, PyTorch 2.15.0+cpu; зависимости закреплены общим окружением. Один CPU-поток, без GPU и сети. Используются 27 коротких авторских синтетических предложений;21train и 6validation. Это корпус искусственной грамматики, не копия внешних текстов и не реальные ответы кандидатов. Нужны несколько свободных GB для runtime Torch; сама модель мала.

Сеть действительно обучается: token и position embeddings, один causal attention-блок, residual-связи, LayerNorm, feed-forward и проекция в словарь. Размерность 16, словарь 23,300 шагов AdamW. Split сделан по целым предложениям до формирования тензоров. Padding исключён из loss. Unigram baseline оценивает частоты только на train.

Авторский прогон: начальный validation NLL≈3.50374, финальный≈0.61198, unigram NLL≈2.88079, perplexity≈1.84407. `causal_prefix_max_abs_error=0.0`: изменение последнего входного токена не меняет ранние logits. Проверки требуют этой причинности и улучшения относительно начального состояния и unigram. В другой версии библиотек небольшие численные отличия допустимы.

Генерации проверенного запуска: `red fox sits.`, `blue dog sits.`, `green dog jumps.`. Они не доказывают владение английским или пригодность к интервью: модель изучила узкий синтетический шаблон. Цель — проследить настоящее обучение и ограничения.

Файлы в `artifacts/M08/`: `report.json`, `history.json`, `corpus.json`, `model.pt`. Для собственной работы добавь новую грамматическую конструкцию, пересмотри split по комбинациям и сохрани новую версию корпуса. Перед повторным запуском сохрани предыдущий отчёт в submissions, если хочешь сравнить изменения.

## Расширение 1.2.0: языковая модель с нуля (M08-L08X)

```powershell
.\.venv\Scripts\python.exe labs\M08\gpt_from_scratch.py report
.\.venv\Scripts\python.exe labs\M08\gpt_from_scratch.py run --config small --steps 300
.\.venv\Scripts\python.exe labs\M08\gpt_from_scratch.py run
```

Корпус — текст этого курса: уроки, ключи, страницы модулей и инструкции лабораторных, около 2.7 МБ. Файлы целиком делятся по хешу пути на обучение, проверку и тест; сам урок M08-L08X в корпус не входит. Byte-level BPE на 4096 токенов учится только на обучающей части. Затем две GPT с ручным вниманием обучаются по 1200 шагов: small на 1.35 млн и plan на 10.48 млн параметров. Нужны только PyTorch и regex из окружения курса, без сети и скачиваний.

`report` печатает замороженный прогон из `quality/gpt-from-scratch` за секунду. Короткий прогон small занимает несколько минут. Полный прогон шёл у автора около 61 минуты на 8 потоках CPU. Прогон пишет `artifacts/M08/gpt/report.json` и `bpe.json`; веса моделей не сохраняются.

Авторский прогон 09.11.2026 на корпусе коммита 57486b8, тест — 144 669 байт: plan — 0.894 бита на байт, small — 1.137, биграмма — 1.343, lzma, которому показан обучающий текст, — 1.120. Корпус меняется вместе с курсом, поэтому повторный прогон даст близкие, но не те же числа. Тесты `tests/test_gpt_from_scratch.py` проверяют слияния BPE на ручном примере, причинность, ручное внимание против PyTorch, формулу параметров и согласованность замороженного отчёта.
