# M04. Локальная лабораторная

Версия практики 1.1.0: первоначальная demo.py остаётся разобранным примером. Обязательное продолжение — `bridges.py` и новая самостоятельная HW, которая использует другие пары.

## Восстановление вероятности и планирование объёма

Из корня курса: `.\.venv\Scripts\python.exe labs\M04\bridges.py`.

Скрипт проверяет хвосты малых биномиальных распределений, затем симулирует план фиксированного эксперимента. `output/planning.json` содержит параметры, exact/Monte Carlo power и SE самой симуляции. При известном p₀=.6 и p₁=.7 первая подходящая величина из [50,100,200,400] — n=200. Для p₁=.65 из [100,200,400,800] — n=800. Парный пример improve=.15,regress=.05 тоже выбирает200 из первой сетки; это отдельная модель предположений, а не вывод о настоящем продукте.

Сравни симуляцию и exact_power. В повторном парном примере improve=.10,regress=.05 при n=400 симуляция seed75≈.7983, точная мощность≈.802071. Погрешность симуляции объясняет пересечение порога .8; нельзя выбирать удачный seed вместо анализа.

Ресурсы: CPU, небольшие массивы, NumPy/SciPy из окружения; платного сервиса и данных из сети нет. Подготовленные вероятности не заменяют независимые человеческие наблюдения. Инструкции и теория: [M04-L06](../../course/lessons/M04-L06.md), [M04-L07](../../course/lessons/M04-L07.md), [M04-L08](../../course/lessons/M04-L08.md).

Самостоятельная работа: [стартер и checker](../../exercises/M04/README.md). После попытки полный ключ `.\.venv\Scripts\python.exe solutions\exercises\M04\run_hw.py` создаёт отдельный `artifacts/foundation-hw/M04/report.json`. Для новой HW: эффект .2, p=.625, bootstrap[-.2,.6]; демонстрационный отчёт ниже относится к прежним учебным данным, а не к этой HW.

**Цель:** воспроизвести вычисления модуля «Вероятность и статистика», проверить содержательные инварианты и затем самостоятельно решить изменённый вариант.

## Запуск в Windows PowerShell

Открой терминал и выполни команды по порядку. Первая команда задаёт рабочую папку: относительный путь к Python отсчитывается от неё.

```powershell
Set-Location C:\projects\ml-llm-course
.\.venv\Scripts\python.exe labs\M04\demo.py
```

При успешном выполнении программа печатает JSON, создаёт каталог `output` рядом с `demo.py` и заканчивает с кодом 0. Если окружение ещё не подготовлено, используй [общую инструкцию](../../README.md). Активация venv не требуется, потому что указан путь к его Python.

## Данные и ресурсы

Данные авторские и синтетические: они заданы непосредственно в скрипте либо создаются фиксированным генератором. Чужих разговоров, резюме и персональных данных нет. Интернет, платный API, GPU, Docker и загрузка модели для этой лабораторной не требуются. Достаточно CPU; для учебных массивов разумно иметь 1 ГБ свободной RAM. Это запас для окружения, а не измеренный пик памяти.

Проверено в Python 3.11.9 на Windows, с numpy 2.4.6, pandas 2.3.3, scipy 1.17.1, scikit-learn 1.9.1. Полный состав окружения зафиксирован в [requirements.lock.txt](../../requirements.lock.txt). Необязательные пакеты всего курса могут отсутствовать в конкретном скрипте.

## Ожидаемый результат и наблюдённая проверка

Доли A=0.5,B=0.75, парный эффект 0.25. Bootstrap-интервал [0,0.625], исходных независимых сессий 8, вычислительных повторов 20000. Нетождественных пар 2, знаковый p=0.5. Формула Уилсона сверена со SciPy в шести случаях, включая границы.

Последний локальный проверочный запуск: **1.983 с**, код возврата **0**. Время зависит от нагрузки, холодного импорта и компьютера; оно не является гарантией задержки сервиса. [Полный измеренный результат](output/result.json).

Числа с плавающей точкой сравниваются с допуском, а не текстовым совпадением всех знаков. Где используется случайность, seed и размеры зафиксированы в коде. Изменение seed может изменить статистический результат; не меняй данные ради совпадения с желаемой метрикой.

## Как выполнить самостоятельно

1. Прочитай пять уроков из [оглавления модуля](../../course/modules/M04.md) и реши короткие задачи.
2. До запуска запиши ожидаемые ключевые числа и возможную ошибку контракта.
3. Запусти пример, сопоставь вывод с ручным расчётом и проверь, какой assert обнаруживает содержательную ошибку.
4. Создай свой файл в `submissions/M04` и выполни M04-HW01 из оглавления, затем новый вариант.
5. Открой [ключи](../../solutions/modules/M04.md) после собственной попытки. Укажи использованную помощь и повтори задачу с другими условиями.

`demo.py` — эталонный исполняемый пример, поэтому его запуск не засчитывает самостоятельное выполнение. Для самопроверки важны объяснение, собственный вариант и обработка неверного входа, а не наличие файла с правильным названием.
