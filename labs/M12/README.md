# M12: настоящая малая языковая модель и адаптер

Цель: увидеть изменение вероятностей следующего символа при обучении и проверить регрессию после адаптации. Это **биграммная языковая модель**, а не разговорная LLM. Она рассматривает только предыдущий символ и не понимает инструкций.

## Запуск

```powershell
Set-Location C:\projects\ml-llm-course
.\.venv\Scripts\python.exe labs\M12\demo.py
```

Проверено: Windows, Python 3.11.9, PyTorch 2.15.0+cpu. Требуется установленное окружение курса; GPU и сеть при запуске не нужны. Данные генерируются самим кодом, скачивание не требуется. Всего 25 базовых и 10 адаптерных параметров; расчёт использует один CPU-поток. Время процесса на контрольном запуске — около 8 секунд, включая импорт PyTorch; это наблюдение, а не обещание для другого компьютера. Память определяется главным образом Python/PyTorch, а не крошечными весами.

## Что делает код

1. Формирует строки `ab` разной длины; полные строки train/test различаются.
2. Обучает таблицу логитов переходов между пятью символами.
3. Замораживает базу и обучает добавку ранга 1 на новой грамматике `ac`.
4. Проверяет обе грамматики и побитовое сохранение исходных весов.
5. Сохраняет `artifacts/M12/metrics.json` и `tiny-lm.pt`.

Контрольный результат seed=17: исходная loss 1,60944; база на старой задаче 0,16638; база на новой 3,73176; адаптер на новой 0,56625; адаптер на старой 11,98950. Незначительная численная вариативность допустима. Автоматические assertions требуют улучшения базовой задачи, улучшения новой после адаптации и неизменности базы. **Они намеренно не требуют отсутствия регрессии**: сильное ухудшение старой задачи — предмет анализа.

## Самостоятельное изменение

Скопируй исходник в `submissions/M12-HW01/`, добавь обучение на смеси грамматик и сравни обе потери. Не меняй test после просмотра результатов. Объясни неизбежную неоднозначность перехода `a→b` или `a→c` для модели без дополнительного контекста.

Генерация данных — авторский синтетический пример курса. Он проверяет механизм обучения, не качество реальных интервью. Сохранённый checkpoint содержит тензоры и алфавит; загружай только собственные доверенные артефакты.
