# M13: версия, контракт, наблюдения и откат

Обязательный путь использует стандартную библиотеку Python. Это воспроизводимый эксперимент внутри процесса, а не имитация измеренной промышленной HTTP-нагрузки.

```powershell
Set-Location C:\projects\ml-llm-course
.\.venv\Scripts\python.exe labs\M13\demo.py
```

Проверено на Python 3.11.9, Windows, CPU. GPU, интернет, Docker и платные сервисы не нужны. Синтетические данные определены в исходнике. Результат появляется обычно менее чем за секунду; объём данных — несколько килобайт.

## Ожидаемое поведение

- `active_release` равен `1.0`.
- `bad_release_detected` и `behavior_restored` равны `true`.
- Отклонены четыре невалидных запроса, записаны 100 длительностей.
- В `artifacts/M13/` сохранены два манифеста, JSONL запросов и итоговый отчёт.

Стабильный релиз вычисляет `2*x+1`; ошибочный — `20*x+1`. Canary проверяет три известные точки. После обнаружения ошибки активный объект возвращается к стабильной версии, затем поведение проверяется ещё раз. Задержки `p50_ms`/`p95_ms` измерены для вызова функции и не характеризуют сеть, очередь или много пользователей. Определение p95 — nearest-rank.

Для самопроверки открой JSONL, вычисли квантиль самостоятельно и сравни. Суммы кода изменятся при редактировании исходника: это ожидаемо. Хеш данных фиксирует их канонические байты, но не является оценкой качества.

## Дополнительный Docker

Файл `Dockerfile` демонстрирует упаковку только этого чистого Python-примера. Он не включает Windows SAPI и полный голосовой проект. Если Docker уже установлен, из корня курса можно выполнить:

```powershell
docker build -f labs/M13/Dockerfile -t ml-course-m13 .
docker run --rm ml-course-m13
```

Контейнерный вариант не входит в обязательную проверку на этом ноутбуке: Docker-сборка здесь не заявляется выполненной. Для строгой фиксации образа после получения проверенного digest укажи его вместо изменяемого тега и сохрани в своём отчёте. Отсутствие Docker не мешает пройти модуль.
