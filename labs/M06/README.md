# M06 — выпуск модели, очередь и откат

Из PowerShell сначала перейди в корень курса:

```powershell
Set-Location C:\projects\ml-llm-course
.\.venv\Scripts\python.exe labs\M06\demo.py
```

Python 3.11; только стандартная библиотека. CPU, без GPU, сети и скачивания данных. Программа использует несколько чисел; потребление памяти ограничено обычным небольшим процессом Python. Данные и сценарий созданы для курса.

Ожидаемый результат: `stable_prediction=7`, `broken_prediction=4`, `restored_prediction=7`, `queue_latencies=[2,3,4,5]`, `logical_turns=1`. В `artifacts/M06/report.json` две записи: активирован несовместимый выпуск, затем выполнен откат к `release-A`. Встроенная проверка отвергает повтор того же ключа с изменённым содержимым.

Этот опыт проверяет согласованность preprocessing и весов, семантику очереди и идемпотентность. Он не запускает сетевой сервер и не измеряет реальную задержку LLM. Сценарные секунды — вход симуляции.

Самостоятельная модификация: измени среднее в новом выпуске, добавь контрольный вход, который находится вне среднего, и докажи восстановление. Затем смоделируй обслуживание по одной секунде для приходов `[0,0.5,1,4]`; ожидаются задержки `[1,1.5,2,1]`. Не убирай проверки, чтобы «исправить» неудачный запуск: сначала объясни нарушенный инвариант.
