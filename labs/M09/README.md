# M09 — реальная компактная LLM локально

Обязательная модель: `HuggingFaceTB/SmolLM2-135M-Instruct`, ревизия `12fd25f77366fa6b3b4b768ec3050bf629380bac`, [официальная карточка](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct), лицензия Apache2.0. Карточка и provenance сохраняются рядом с файлами. Модель преимущественно английская; качество русского интервью не заявлено.

В подготовленной папке веса уже скачаны. Обычный запуск полностью локален:

```powershell
Set-Location C:\projects\ml-llm-course
.\.venv\Scripts\python.exe labs\M09\demo.py
```

Для воспроизведения после удаления папки `models/smollm2-135m-instruct` скачай закреплённые файлы из официального Hub:

```powershell
.\.venv\Scripts\python.exe labs\M09\demo.py --download
```

Первое скачивание требует сети, но не платного API и не аккаунта. Авторский набор файлов занимал272444345байт. Обычный запуск использует `local_files_only=True` и не подгружает другую ревизию. Нужны CPU, несколько свободных GB RAM и около300MB на файлы модели; GPU не используется. При загрузке float32 сами параметры занимают538060032байта, но полный процесс требует больше памяти.

Проверено: Python3.11.9, torch2.15.0+cpu, transformers4.57.6, huggingface-hub0.36.2. Используется настоящий `AutoModelForCausalLM`, float32, eager attention,2CPU-потока. Квантование в этом запуске не выполняется; пример int8 из урока — отдельный численный разбор.

Ожидаемые инварианты:134515008параметров, ненулевой вывод, `context_limit=8192`, вход плюс резерв не превышает лимит. Для основного запроса авторский prompt занимал31токен, генерация21токен. Один наблюдавшийся запуск: загрузка≈2.59с, полный generate≈2.23с. Это замер конкретного окружения, не SLO и не TTFT; текущая нагрузка изменит время.

Фактический ответ был кратким, но круговым определением SQL transaction. На запрос JSON модель выдала Python-код. Валидатор вернул `invalid_json`, `fallback_used=true`. Такой результат является успешной проверкой обработки отказа, а не успешной оценкой кандидата. Не заменяй исходный output эталоном, чтобы сделать отчёт красивее.

`artifacts/M09/report.json` содержит реальные ответы, фактический шаблон, числа токенов, ревизию и времена. После запуска вручную оцени содержание. Для новых экспериментов сохраняй отдельные отчёты. Проверка схемы отвергает пустой feedback, boolean вместо целого score и неверный JSON; синтаксическая корректность сама по себе не подтверждает технические факты.
