# M05. Локальная лабораторная

Версия 1.1.0. Здесь две ступени: исходный пример регрессии `demo.py` и обязательный mixed-data классификатор `pipeline.py`. Домашняя работа использует отдельные данные и условия в exercises/M05; запуск демонстрации не является её решением.

## Классификация, preprocessing и аудит fit

Из корня курса:

```powershell
.\.venv\Scripts\python.exe labs\M05\pipeline.py --variant demo
```

Данные создаются локально из seed120,240 строк. CPU, pandas/NumPy/scikit-learn/joblib из существующего lockfile; GPU и сеть не нужны. Воспроизводимый результат сохраняется в `labs/M05/output/demo/`: CSV, report.json и classifier.joblib. Пример выбирает C и порог на validation, затем оценивает test. Проверяются восстановление артефакта, неизвестная категория, неизменность предсказаний при подмене будущего столбца и фактические ID fit.

В проверенном опыте выбран C=1, threshold=.25; test log loss≈.503443 против baseline≈.712099. Confusion[1,20,0,27] показывает высокую цену выбранного низкого порога по FP: не скрывай её за средней потерей. При одинаковом C=.1 и scaler смена единиц опыта в1000раз сохраняет validation log loss≈.517896; без scaler результаты отличаются. Достаточно небольшого численного допуска, а не совпадения всех последних знаков.

Три намеренно неправильных global-fit опыта отклоняются по ID, даже если метрика могла бы быть хорошей. Важна процедура, а не искусственно гарантированный размер вреда утечки.

Для самостоятельной работы прочитай [M05-L06](../../course/lessons/M05-L06.md), [M05-L07](../../course/lessons/M05-L07.md) и [стартер/контракт](../../exercises/M05/README.md). Полный ключ HW находится в `solutions/exercises/M05/run_hw.py`; это отдельный сценарий с пересекающей границу группой. Проверь восстановление модели в новом процессе. Команды `--variant retry` и `--variant delayed` у полного ключа меняют не только данные, но и указанное в задании условие. Начинай их после своей попытки.

**Цель:** воспроизвести вычисления модуля «Классический ML», проверить содержательные инварианты и затем самостоятельно решить изменённый вариант.

## Запуск в Windows PowerShell

Открой терминал и выполни команды по порядку. Первая команда задаёт рабочую папку: относительный путь к Python отсчитывается от неё.

```powershell
Set-Location C:\projects\ml-llm-course
.\.venv\Scripts\python.exe labs\M05\demo.py
```

При успешном выполнении программа печатает JSON, создаёт каталог `output` рядом с `demo.py` и заканчивает с кодом 0. Если окружение ещё не подготовлено, используй [общую инструкцию](../../README.md). Активация venv не требуется, потому что указан путь к его Python.

## Данные и ресурсы

Данные авторские и синтетические: они заданы непосредственно в скрипте либо создаются фиксированным генератором. Чужих разговоров, резюме и персональных данных нет. Интернет, платный API, GPU, Docker и загрузка модели для этой лабораторной не требуются. Достаточно CPU; для учебных массивов разумно иметь 1 ГБ свободной RAM. Это запас для окружения, а не измеренный пик памяти.

Проверено в Python 3.11.9 на Windows, с numpy 2.4.6, pandas 2.3.3, scipy 1.17.1, scikit-learn 1.9.1. Полный состав окружения зафиксирован в [requirements.lock.txt](../../requirements.lock.txt). Необязательные пакеты всего курса могут отсутствовать в конкретном скрипте.

## Ожидаемый результат и наблюдённая проверка

Сравниваются средний прогноз, линейная модель, два дерева и бустинг. Выбор использует только validation. На зафиксированном синтетическом наборе выбран boosting; ниже приведены реальные локальные измерения, а не обещание результата на пользовательских интервью.

| Модель | Validation MAE | Validation MSE |
|---|---:|---:|
| mean | 2.237738 | 7.024135 |
| linear | 2.217315 | 7.043299 |
| tree_depth_2 | 0.925911 | 1.204785 |
| tree_depth_4 | 0.409823 | 0.254321 |
| boosting | 0.216328 | 0.073898 |

Выбранная модель: **boosting**. Test MAE=0.214157, MSE=0.071618. Test не используется для выбора строки таблицы. Срез x<0: n=32, MAE=0.189840; x≥0: n=28, MAE=0.241947. Это наблюдения на синтетике, без вывода о готовности продукта.

Последний локальный проверочный запуск: **3.411 с**, код возврата **0**. Время зависит от нагрузки, холодного импорта и компьютера; оно не является гарантией задержки сервиса. [Полный измеренный результат](output/result.json).

Числа с плавающей точкой сравниваются с допуском, а не текстовым совпадением всех знаков. Где используется случайность, seed и размеры зафиксированы в коде. Изменение seed может изменить статистический результат; не меняй данные ради совпадения с желаемой метрикой.

## Как выполнить самостоятельно

1. Прочитай пять уроков из [оглавления модуля](../../course/modules/M05.md) и реши короткие задачи.
2. До запуска запиши ожидаемые ключевые числа и возможную ошибку контракта.
3. Запусти пример, сопоставь вывод с ручным расчётом и проверь, какой assert обнаруживает содержательную ошибку.
4. Создай свой файл в `submissions/M05` и выполни M05-HW01 из оглавления, затем новый вариант.
5. Открой [ключи](../../solutions/modules/M05.md) после собственной попытки. Укажи использованную помощь и повтори задачу с другими условиями.

`demo.py` — эталонный исполняемый пример, поэтому его запуск не засчитывает самостоятельное выполнение. Для самопроверки важны объяснение, собственный вариант и обработка неверного входа, а не наличие файла с правильным названием.
