# Улучшение курса до версии 1.2.0

Рабочий бэклог — `IMPROVEMENT_PLAN.md`. Доказательная база и источники — `quality/research-2026-11-03.md`. Перед любой задачей прочитать разделы 0–3 плана.

## Правила

- Ничего не удалять и не сокращать: уроки, задачи A/B/C, решения, лабораторные, ноутбуки, тесты, отрицательные результаты экспериментов. Разрешены добавление, переименование заголовков по словарю (план, раздел 3.3), перенос ссылок, метаданные.
- Первая задача любой сессии улучшений — убедиться, что есть `tools/check_no_loss.py` (T05) и снимок `quality/snapshots/baseline-1.1.0.json`. Без них правки уроков не начинать.
- Одна задача = один коммит с ID задачи в сообщении. После задачи — протокол проверки из раздела 2 плана и отметка в разделе 7.
- Новые уроки — с суффиксом `X` и пометкой «Расширение 1.2.0». Обязательный путь курса остаётся бесплатным, локальным, на CPU, без сети.
- Остановиться и спросить автора: URL репозитория, загрузка моделей больше 1 ГБ, новые обязательные зависимости, любое необратимое действие.
- Окружение Windows/PowerShell: `.\.venv\Scripts\python.exe`. Зависимости не ставить глобально; опциональные пакеты — в `requirements-optional.in`.
- Не запускать генераторы из `.authoring` (или из архива `archive/`).
