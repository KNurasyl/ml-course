# Шпаргалка: карточки уроков

Страница собрана `tools/build_cheatsheet.py` из разделов «Карточка урока»; вручную её не правят. Карточек: 5 из 103 уроков. Карточка помогает вспомнить правило перед отложенной проверкой, но не заменяет решение задачи: сначала попробуй восстановить правило сам, затем сверься.

Те же карточки в виде пар «вопрос — ответ» сохраняются в `artifacts/anki-cards.csv` для импорта в Anki (Файл → Импорт; разделитель и столбцы указаны в заголовке файла).

## M00. Модель и обучение

### [M00-L01. От входа к предсказанию](lessons/M00-L01.md)

- **Правило.** ŷ = f(x); для линейной модели ŷ = w·x + b. Инференс — применение готового правила к новому входу, правило при этом не меняется.
- **Смысл величин.** x — вход, его смысл и единицы задаёт инженер; ŷ — предсказание; y — известный правильный ответ; w и b — числа, задающие правило.
- **Когда применять.** Всякий раз, когда нужно отделить вычисление ответа от подбора правила. Пример: ŷ = 2x + 1 при x = 3 даёт 7, повторный вызов с другим x правило не меняет.
- **Главная ошибка.** Считать вызов модели обучением или путать предсказание ŷ с правильным ответом y.

### [M00-L02. Параметры и устройство модели](lessons/M00-L02.md)

- **Правило.** Архитектура — вид вычисления (w·x + b), параметры — конкретные числа w и b, состояние приложения — данные вне модели, например история запросов.
- **Смысл величин.** w — наклон: при росте x на 1 ответ меняется на w; b — ответ при x = 0, его изменение сдвигает все ответы одинаково.
- **Когда применять.** При сохранении, загрузке и выпуске модели: релиз = архитектура + параметры + порядок признаков + подготовка входа + версия. Пример: b с 1 на 3 сдвигает все ответы на +2.
- **Главная ошибка.** Сохранять параметры без архитектуры и версии или считать запись истории запросов изменением параметров.

### [M00-L03. Ошибка и подбор параметров](lessons/M00-L03.md)

- **Правило.** MSE = (e₁² + … + eₙ²)/n, где eᵢ = ŷᵢ − yᵢ; кандидатов сравнивают на одних и тех же объектах по одному правилу.
- **Смысл величин.** eᵢ — остаток (плюс — завышение, минус — занижение); квадрат усиливает большие промахи; n — число объектов, при n = 0 ошибка не определена; единицы MSE — квадрат единиц y.
- **Когда применять.** При выборе параметров по таблице с известными ответами. Пример: остатки [1, −1, 2] дают MSE = (1 + 1 + 4)/3 = 2.
- **Главная ошибка.** Усреднять остатки без квадрата, так что ошибки разных знаков гасят друг друга, или выдавать меньшую MSE на обучающей таблице за качество на новых данных.

### [M00-L04. Обучение и применение](lessons/M00-L04.md)

- **Правило.** Обучение меняет обучаемые параметры по данным и цели; инференс применяет модель; контекст — содержимое одного вызова; история и индекс — данные приложения.
- **Смысл величин.** Веса — обучаемые параметры (все или только адаптер); контекст — токены конкретного запроса; RAG-индекс — корпус, из которого ищут фрагменты для контекста.
- **Когда применять.** При разборе вопроса «почему ответ изменился или не изменился»: проследи, какой артефакт поменяло действие — веса, контекст, историю или индекс.
- **Главная ошибка.** Считать, что сохранённая история или новый документ в корпусе меняют веса модели или сами попадают в контекст.

### [M00-L05. Первая схема ML-сервиса](lessons/M00-L05.md)

- **Правило.** Два контура: подготовка модели (данные, обучение, оценка, артефакт) и запрос (контракт, загрузка версии, инференс, ответ); запрос модель не обучает.
- **Смысл величин.** Контракт — тип, допустимые значения и единицы входа; артефакт — параметры, подготовка входа и версия; откат — возврат всего совместимого набора.
- **Когда применять.** При проектировании и выпуске сервиса: каждая стрелка схемы подписана передаваемыми данными, центр и масштаб хранятся и откатываются вместе с весами.
- **Главная ошибка.** Откатывать только веса, оставив подготовку входа от новой версии, или считать быстрый ответ без ошибок доказательством правильных предсказаний.
