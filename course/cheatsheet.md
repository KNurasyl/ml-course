# Шпаргалка: карточки уроков

Страница собрана `tools/build_cheatsheet.py` из разделов «Карточка урока»; вручную её не правят. Карточек: 20 из 103 уроков. Карточка помогает вспомнить правило перед отложенной проверкой, но не заменяет решение задачи: сначала попробуй восстановить правило сам, затем сверься.

Те же карточки в виде пар «вопрос — ответ» сохраняются в `artifacts/anki-cards.csv` для импорта в Anki (Файл → Импорт; разделитель и столбцы указаны в заголовке файла).

## M00. Модель и обучение

### [M00-L01. От входа к предсказанию](lessons/M00-L01.md)

- **Правило.** ŷ = f(x); для линейной модели ŷ = w·x + b. Инференс — применение готового правила к новому входу, правило при этом не меняется.
- **Смысл величин.** x — вход, его смысл и единицы задаёт инженер; ŷ — предсказание; y — известный правильный ответ; w и b — числа, задающие правило.
- **Когда применять.** Всякий раз, когда нужно отделить вычисление ответа от подбора правила. Пример: ŷ = 2x + 1 при x = 3 даёт 7, повторный вызов с другим x правило не меняет.
- **Главная ошибка.** Считать вызов модели обучением или путать предсказание ŷ с правильным ответом y.

### [M00-L02. Параметры и устройство модели](lessons/M00-L02.md)

- **Правило.** Архитектура — вид вычисления (w·x + b), параметры — конкретные числа w и b, состояние приложения — данные вне модели, например история запросов.
- **Смысл величин.** w — наклон: при росте x на 1 ответ меняется на w; b — ответ при x = 0, его изменение сдвигает все ответы одинаково.
- **Когда применять.** При сохранении, загрузке и выпуске модели: релиз = архитектура + параметры + порядок признаков + подготовка входа + версия. Пример: b с 1 на 3 сдвигает все ответы на +2.
- **Главная ошибка.** Сохранять параметры без архитектуры и версии или считать запись истории запросов изменением параметров.

### [M00-L03. Ошибка и подбор параметров](lessons/M00-L03.md)

- **Правило.** MSE = (e₁² + … + eₙ²)/n, где eᵢ = ŷᵢ − yᵢ; кандидатов сравнивают на одних и тех же объектах по одному правилу.
- **Смысл величин.** eᵢ — остаток (плюс — завышение, минус — занижение); квадрат усиливает большие промахи; n — число объектов, при n = 0 ошибка не определена; единицы MSE — квадрат единиц y.
- **Когда применять.** При выборе параметров по таблице с известными ответами. Пример: остатки [1, −1, 2] дают MSE = (1 + 1 + 4)/3 = 2.
- **Главная ошибка.** Усреднять остатки без квадрата, так что ошибки разных знаков гасят друг друга, или выдавать меньшую MSE на обучающей таблице за качество на новых данных.

### [M00-L04. Обучение и применение](lessons/M00-L04.md)

- **Правило.** Обучение меняет обучаемые параметры по данным и цели; инференс применяет модель; контекст — содержимое одного вызова; история и индекс — данные приложения.
- **Смысл величин.** Веса — обучаемые параметры (все или только адаптер); контекст — токены конкретного запроса; RAG-индекс — корпус, из которого ищут фрагменты для контекста.
- **Когда применять.** При разборе вопроса «почему ответ изменился или не изменился»: проследи, какой артефакт поменяло действие — веса, контекст, историю или индекс.
- **Главная ошибка.** Считать, что сохранённая история или новый документ в корпусе меняют веса модели или сами попадают в контекст.

### [M00-L05. Первая схема ML-сервиса](lessons/M00-L05.md)

- **Правило.** Два контура: подготовка модели (данные, обучение, оценка, артефакт) и запрос (контракт, загрузка версии, инференс, ответ); запрос модель не обучает.
- **Смысл величин.** Контракт — тип, допустимые значения и единицы входа; артефакт — параметры, подготовка входа и версия; откат — возврат всего совместимого набора.
- **Когда применять.** При проектировании и выпуске сервиса: каждая стрелка схемы подписана передаваемыми данными, центр и масштаб хранятся и откатываются вместе с весами.
- **Главная ошибка.** Откатывать только веса, оставив подготовку входа от новой версии, или считать быстрый ответ без ошибок доказательством правильных предсказаний.

## M01. Данные и численный Python

### [M01-L01. Массивы и формы](lessons/M01-L01.md)

- **Правило.** Строка — объект, столбец — признак; mean(axis=0) даёт среднее каждого признака; broadcasting сравнивает размеры справа налево, каждая пара должна совпадать или содержать 1.
- **Смысл величин.** shape — число элементов по осям; axis — ось, которая исчезает при сокращении; (3,) — одна ось, (3, 1) — столбец, (1, 3) — строка; dtype — общий тип элементов.
- **Когда применять.** Перед каждой операцией над массивами: выпиши формы входов и ожидаемую форму результата. Пример: (4, 2) − (2,) вычитает вектор из каждой строки и даёт (4, 2).
- **Главная ошибка.** Вычесть (n,) и (n, 1) и получить матрицу n×n вместо n остатков или усреднить по axis=1 признаки в разных единицах.

### [M01-L02. Качество таблицы](lessons/M01-L02.md)

- **Правило.** Сначала определи единицу наблюдения и первичный ключ, затем ищи конфликты ключа, пропуски и нарушения диапазона; каждое правило очистки записывает, что сделано и со сколькими строками.
- **Смысл величин.** Единица наблюдения — что представляет строка; первичный ключ — поля, уникально задающие строку; пропуск — неизвестное значение, а не ноль; доля пропусков = пропуски / строки.
- **Когда применять.** До обучения и при каждом новом источнике данных. Пример: 2 пропуска на 8 строк дают долю 0.25, и причину пропусков нужно выяснить до заполнения.
- **Главная ошибка.** Заменять пропуск нулём или удалять «дубликаты» без проверки, что строки с одним ключом действительно одинаковы.

### [M01-L03. Разделение данных](lessons/M01-L03.md)

- **Правило.** Train — подбор параметров, validation — выбор настроек, test — однократная оценка выбранной процедуры; разбиение повторяет будущий сценарий: по группам, по времени или со стратификацией.
- **Смысл величин.** Группа — связанные строки одного пользователя или сессии, они целиком в одной части; временная граница — прошлое для обучения, будущее для проверки; seed и список ключей делают разбиение воспроизводимым.
- **Когда применять.** До любой подготовки, которая узнаёт свойства данных. Пример: для модели на новых людях обе строки пользователя A попадают в одну часть, а не делятся между train и test.
- **Главная ошибка.** Случайно делить строки одного пользователя между train и test или выбирать лучшую версию по test.

### [M01-L04. SQL и происхождение данных](lessons/M01-L04.md)

- **Правило.** JOIN один-ко-многим повторяет родительскую строку по числу дочерних; признаки уровня сессии получают агрегацией дочерней таблицы до одной строки на ключ, затем проверяют уникальность ключа.
- **Смысл величин.** COUNT(*) — число строк, COUNT(column) — число известных значений; AVG пропускает NULL; LEFT JOIN сохраняет левые строки, но WHERE по правому полю может их удалить.
- **Когда применять.** При сборке признаков из нескольких таблиц. Пример: сессии длятся 20 и 40 с, у первой три ответа — после JOIN среднее (20·3 + 40)/4 = 25 вместо 30.
- **Главная ошибка.** Усреднять поле родителя после JOIN или фильтровать LEFT JOIN условием WHERE по полю правой таблицы.

### [M01-L05. Воспроизводимый конвейер](lessons/M01-L05.md)

- **Правило.** fit вычисляет параметры подготовки только на train и сохраняет их; transform применяет сохранённые параметры к любому входу; центрирование: z = x − μ_train.
- **Смысл величин.** μ_train — среднее обучающей части; артефакт — имена и порядок признаков, статистики и версия; seed — состояние генератора случайных чисел, а не версия данных.
- **Когда применять.** При подготовке признаков для обучения и для сервиса. Пример: train [2, 6], μ = 4; новый x = 9 даёт z = 5, а среднее test после transform не обязано быть нулём.
- **Главная ошибка.** Вызывать fit_transform на test или в сервисе, менять порядок признаков без проверки имён, загружать непроверенный pickle.

## M02. Линейная алгебра

### [M02-L01. Векторы как признаки](lessons/M02-L01.md)

- **Правило.** Вектор — упорядоченный набор чисел; сложение и умножение на число выполняются покоординатно; линейная комбинация αu + βv; разность v − u — изменение по каждой координате.
- **Смысл величин.** Координата — признак в договорённом порядке; α и β — веса комбинации; e₁ и e₂ — базисные направления, x = x₁e₁ + x₂e₂.
- **Когда применять.** Чтобы представить объект признаками или найти изменение между двумя объектами. Пример: u = (4, 1), v = (6, 5) дают v − u = (2, 4) и 0.5u + 0.5v = (5, 3).
- **Главная ошибка.** Переставить координаты или складывать идентификаторы и коды категорий как обычные числа.

### [M02-L02. Скалярное произведение и нормы](lessons/M02-L02.md)

- **Правило.** u·v = Σuᵢvᵢ; ‖u‖ = √Σuᵢ²; cosine = u·v / (‖u‖·‖v‖) для ненулевых векторов, значение от −1 до 1.
- **Смысл величин.** Dot зависит и от длин, и от угла; норма — длина вектора; косинус — сходство направлений; у нулевого вектора направления нет.
- **Когда применять.** Косинус — чтобы сравнить направления, dot — чтобы посчитать вклад признаков в w·x. Пример: u = (1, 2), v = (2, 4) дают cosine = 1, а dot = 10 растёт вместе с длиной v.
- **Главная ошибка.** Делить на нулевую норму без явного правила или считать большой dot большим сходством направлений.

### [M02-L03. Матрицы и композиция](lessons/M02-L03.md)

- **Правило.** (n×d)·(d×k) = n×k: внутренние размеры совпадают; элемент (i, j) — строка i на столбец j; BAx — сначала A, затем B; в общем случае AB ≠ BA.
- **Смысл величин.** n — объекты, d — признаки, k — выходы; транспонирование меняет оси местами; ассоциативность (BA)x = B(Ax) позволяет заранее объединить линейные шаги.
- **Когда применять.** При каждой формуле с матрицами — выписать формы. Пример: X формы (4, 3) и W формы (3, 6) дают XW формы (4, 6).
- **Главная ошибка.** Перемножать по внешним размерам, «чинить» ошибку формы транспонированием наугад или менять порядок преобразований.

### [M02-L04. Сходство и масштаб](lessons/M02-L04.md)

- **Правило.** d(x, z) = √Σ(xᵢ − zᵢ)²; стандартизация zᵢ = (xᵢ − μᵢ)/sᵢ с μ и s по train; нормирование x/‖x‖ работает по строке объекта.
- **Смысл величин.** μᵢ и sᵢ — среднее и разброс признака на train; стандартизация идёт по столбцам, нормирование — по строкам; при sᵢ = 0 делить нельзя.
- **Когда применять.** Перед сравнением объектов по расстоянию, если признаки в разных единицах. Пример: признак в миллисекундах вместо секунд увеличивает свой вклад в квадрат расстояния в миллион раз.
- **Главная ошибка.** Путать стандартизацию столбцов с нормированием строк или вычислять μ и s по всем данным вместе с test.

### [M02-L05. Маленький векторный поиск](lessons/M02-L05.md)

- **Правило.** Точный поиск: нормировать ненулевые векторы, оценки = D̂q̂, взять top-k по убыванию с правилом равенства; recall@k = найденные релевантные / все релевантные.
- **Смысл величин.** q̂ и d̂ — векторы единичной длины, их скалярное произведение равно косинусу; k — размер выдачи; оценка сходства — не вероятность истинности.
- **Когда применять.** Поиск по небольшому корпусу как эталон для проверки приближённых индексов. Пример: релевантны 3 документа, в top-5 найдено 2 — recall@5 = 2/3.
- **Главная ошибка.** Сравнивать векторы разных encoder, оставлять равенства без детерминированного порядка или считать высокий косинус доказательством ответа.

## M03. Производные и оптимизация

### [M03-L01. Изменение функции](lessons/M03-L01.md)

- **Правило.** Производная — предел [f(w + h) − f(w)]/h при h → 0; центральная разность [f(w + h) − f(w − h)]/(2h) обычно точнее при том же h.
- **Смысл величин.** f(w) — высота графика, f′(w) — наклон: его знак показывает направление роста; h — шаг приближения.
- **Когда применять.** Чтобы оценить наклон или проверить формулу производной численно. Пример: f(w) = w² + 3w при w = 1 даёт f′ = 2w + 3 = 5.
- **Главная ошибка.** Путать значение функции с наклоном, брать слишком маленький h или считать нулевой наклон гарантией минимума.

### [M03-L02. Производная и цепное правило](lessons/M03-L02.md)

- **Правило.** Если L = f(g(w)), то dL/dw = f′(g(w))·g′(w); для L = (wx + b − y)²: ∂L/∂w = 2e·x и ∂L/∂b = 2e, где e = ŷ − y.
- **Смысл величин.** e — остаток; 2e — чувствительность потери к предсказанию; x — чувствительность предсказания к весу; частная производная меняет один параметр при фиксированных остальных.
- **Когда применять.** Чтобы вычислить градиент составной функции и проверить его центральной разностью. Пример: x = −1, y = 2, w = 3, b = 0 дают ŷ = −3, e = −5, ∂L/∂w = 10, ∂L/∂b = −10.
- **Главная ошибка.** Забыть множитель x или проверять градиент той же переписанной формулой вместо конечной разности.

### [M03-L03. Градиент на наборе](lessons/M03-L03.md)

- **Правило.** ∂L/∂w = (2/n)Σeᵢxᵢ и ∂L/∂b = (2/n)Σeᵢ; шаг w ← w − η·dw, b ← b − η·db, обе производные считаются по старым параметрам.
- **Смысл величин.** eᵢ — остаток i-го объекта; n — число объектов; η — шаг обучения; в матричной записи dw = (2/n)Xᵀe.
- **Когда применять.** Чтобы обучить линейную модель полным или мини-пакетным градиентом. Пример: x = [1, 2], y = [3, 5], w = b = 0 дают dw = −13 и db = −8.
- **Главная ошибка.** Обновить w и затем считать db по новому w или взять сумму вместо среднего, так что шаг начинает зависеть от размера набора.

### [M03-L04. Шаг обучения](lessons/M03-L04.md)

- **Правило.** Для L = c(w − m)² ошибка параметра δ = w − m меняется как δ_new = (1 − 2cη)δ; спуск сходится при 0 < η < 1/c.
- **Смысл величин.** η — шаг; 1 − 2cη — множитель ошибки за шаг: от 0 до 1 — монотонное приближение, от −1 до 0 — затухающие колебания, по модулю больше 1 — расходимость.
- **Когда применять.** Чтобы выбрать шаг и объяснить медленное обучение, колебания или рост потери. Пример: c = 4 даёт границу η < 0.25; при η = 0.2 множитель равен −0.6.
- **Главная ошибка.** Лечить расходимость большим числом эпох или путать рост validation-ошибки при переобучении с численной расходимостью.

### [M03-L05. Регуляризация и масштаб](lessons/M03-L05.md)

- **Правило.** J = MSE + λw², градиент dJ/dw = dMSE/dw + 2λw; для J = (w − a)² + λw² оптимум w* = a/(1 + λ).
- **Смысл величин.** λ ≥ 0 — сила штрафа; смещение b не штрафуется; штраф тянет вес к нулю, но не делает его точно нулевым.
- **Когда применять.** Чтобы ограничить величину весов; λ выбирают на validation. Пример: a = 9 и λ = 0.5 дают w* = 6.
- **Главная ошибка.** Штрафовать признаки в разных масштабах одним λ без стандартизации или подбирать λ по test.
