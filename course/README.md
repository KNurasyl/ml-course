# ML и LLM: локальный самоучитель

Научись объяснять, обучать и проверять модели, а затем собери голосовой тренажёр собеседований. Читай теорию, исследуй схемы, решай задачи и сравнивай свою попытку с отдельным разбором.

**10 вводных занятий · 17 модулей · 103 урока.** Материалы версии 1.1.0 доступны целиком. Учебник работает локально, без аккаунта и сервера. Оформление 2.0 добавляет карту урока, поиск по фрагментам и адаптивные схемы.

## Начни здесь

1. Прочитай [как учиться самостоятельно](self-study.md): там описано, когда открывать решения и как проверять понимание.
2. Выполни [входную диагностику](diagnostic.md). На неизвестное можно ответить «пока не знаю». Сохрани первую попытку до просмотра ключей.
3. Сверься с [ключами диагностики](../solutions/pilot/answer-key.md), отметь пробелы и переходи к [P01 — первой модели](pilot/P01.md).

Не нужно ждать ответа в чате или разрешения на следующий урок. Если расчёт, объяснение и новый вариант сходятся с критериями, переходи дальше. При критической ошибке сначала исправь её и реши новую задачу.

## Чтение и практика

Урок — это текст в учебнике. Ноутбук — файл, где можно выполнять Python по частям и видеть результат. Чтение урока не требует запуска Python.

Для практики открой папку C:\projects\ml-llm-course и дважды щёлкни **START_PRACTICE.cmd**. Он запустит Jupyter с правильным окружением и папкой. В браузере выбери notebooks → pilot → нужный файл P01.ipynb … P10.ipynb. Окно запуска оставь открытым, пока работаешь.

Перед изменениями сделай копию ноутбука внутри submissions. Если копия лежит глубже, используй оглавление учебника для переходов к теории: относительные ссылки в исходном ноутбуке рассчитаны на его исходную папку.

Если удобнее PowerShell, эта команда работает из любой папки:

```powershell
& "C:\projects\ml-llm-course\.venv\Scripts\python.exe" -m jupyterlab --ServerApp.root_dir="C:\projects\ml-llm-course"
```

Среда уже подготовлена: Python 3.11, CPU, небольшие синтетические данные. Обязательные задания пилота не используют платные API, GPU или интернет после установки зависимостей.
