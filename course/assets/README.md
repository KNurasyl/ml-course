# Схемы технического учебника

`responsive/` содержит 104 пары SVG: вариант для широкой страницы и отдельную
компоновку для телефона. Числа обоих вариантов одинаковы. Соответствие исходным
рисункам задано в `metadata/responsive-figures.json`; HTML-учебник выбирает
компоновку через `<picture>` и измерение доступной ширины рисунка: при колонке
уже 600 CSS-пикселей используется узкий вариант, в том числе на планшете рядом
с открытым оглавлением. Исходные PNG/SVG сохранены для происхождения и
обычных Markdown-просмотров; современная версия читается в START_HERE.html.

Рисунок не должен требовать увеличения для чтения основного механизма. Узкие
экраны получают вертикальные панели, а не уменьшенный многопанельный плакат.

Общие правила:

- Данные и вход: синий `#245bba`; действие и результат: бирюзовый `#087e82`.
- Условие, предел и отклонённый путь: охра `#a65c12`.
- На количественных графиках цвета различают серии; значение указывает подпись
  или легенда. На тепловых картах оттенок кодирует число, подписанное в ячейке.
- Текст `#182b3a`, вторичные подписи `#526474`, системный шрифт Segoe UI.
- Цвет всегда сопровождается текстом, обозначением или формой линии.

Воспроизведение из корня репозитория:

```powershell
.\.venv\Scripts\python.exe tools\build_foundation_figures.py
.\.venv\Scripts\python.exe tools\build_quantitative_figures.py
.\.venv\Scripts\python.exe tools\build_responsive_figures.py
.\.venv\Scripts\python.exe tools\build_reader.py
.\.venv\Scripts\python.exe tools\build_manifest.py
```

Эти генераторы работают только с рисунками и их реестрами, не переписывают
тексты курса и не запускают `.authoring`. Для воспроизводимых SVG зафиксированы
hashsalt и отсутствие текущей даты в метаданных.

Основные примеры синтетические; значения и допущения указаны в уроках. Файл
`data/M07-HW01-measurements.json` — сохранённые числа уже проведённого эталонного
прогона M07 (seed=23, noise=0.30, checkpoint=115). Перерисовка читает этот снимок,
не переобучает модель и не создаёт новых свидетельств её качества. M12-L05 также
перерисовывает значения предыдущего CPU-эксперимента; его происхождение описано
в уроке и отчёте 1.1.0.

Адаптивный рисунок — иллюстрация, а не доказательство освоения учеником темы.
