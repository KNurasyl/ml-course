# P08 Обучение через обновление параметров

Занятие P08, версия 0.2.0. Это учебный материал, а не отметка о прохождении. Работа выполняется локально на CPU; платные сервисы не нужны.

Практический файл: [ноутбук P08](../../notebooks/pilot/P08.ipynb). После самостоятельной попытки можно свериться с [эталоном P08](../../solutions/pilot/P08.ipynb). Проверь текстовые ответы и рассуждения по критериям и ключу после своей попытки. Успешный запуск ноутбука сам по себе не подтверждает понимание. Порядок самопроверки описан в руководстве по самостоятельному обучению.

Начальный ориентир занятия — около четырёх часов вместе с перерывами: восстановление предыдущей темы, объяснение, вычисления вручную, лабораторная, самостоятельная задача и разбор. Если необходимая предпосылка не усвоена, сначала выполни корректирующее упражнение. Дополнительный пятый час оставь для завершения работы или спокойного повторения.

Режим AI: первую самостоятельную попытку сделай без готового решения. После неё разрешены подсказки и объяснения. Запиши, какая помощь потребовалась. Полный разбор допустим, но после него самостоятельность проверяется другим примером. Записывай собственное время и не торопись: цель занятия — получить навык, который можно объяснить и воспроизвести.

## Результаты и подготовка

Сегодня ты выполнишь несколько шагов градиентного спуска вручную, реализуешь простой цикл и объяснишь влияние величины шага. Необходимы P02, P04 и P07: средняя ошибка, массивы и производные. Сначала восстанови смысл производной функции ошибки. Если получается только повторить формулу, вернись к численному изменению из предыдущего занятия.

## Правило изменения

Производная показывает локальное направление роста функции по параметру. Чтобы уменьшать ошибку, делаем шаг в противоположную сторону: новый параметр равен старому минус learning rate, умноженный на производную. Learning rate — выбранная величина шага. Она не обучается этим простым алгоритмом, а задаётся разработчиком как настройка процесса.

Для L(w) = (w−3)² производная равна 2(w−3). Начнём с w = 0 и шага 0.1. Производная равна −6, поэтому новый w = 0 − 0.1×(−6) = 0.6. Ошибка уменьшилась с 9 до 5.76. На следующем шаге производная равна −4.8, новый параметр — 1.08, ошибка — 3.6864. Это последовательность локальных улучшений, а не вычисление правильного значения волшебной командой.

Для этой специально простой функции шаг 0.5 сразу приводит к минимуму 3. Слишком большой шаг 1.1 перескакивает через минимум: сначала получается 6.6, затем −1.32. Расстояние до оптимума растёт. Не переноси удачный шаг 0.5 на любую модель: допустимый масштаб зависит от функции, признаков и других условий обучения.

## Два параметра линейной модели

Возьмём x = [0,1,2], y = [1,3,5], предсказание wx+b и начальные параметры w = 0, b = 0. Для средней квадратичной ошибки производная по w равна среднему 2×error×x, а по b — среднему 2×error. Начальные ошибки составляют [-1,−3,−5], поэтому dw = −26/3, db = −6.

При шаге 0.1 новое w равно 13/15, примерно 0.866667, а b равно 0.6. Обе производные вычисляются по старым параметрам, затем оба параметра обновляются. Если сначала изменить w, а затем вычислить db уже по новому w, получится другой алгоритм. На этом этапе мы изучаем одновременный шаг по одному градиенту.

Цикл обучения повторяет предсказание, вычисление ошибки, производных и обновление. Инференс после обучения использует сохранённые w и b без этих обновлений. Поэтому функцию обучения полезно отделить от функции предсказания даже в маленьком учебном коде.

## Практика с поддержкой

Реализуй однопараметрический пример, записывая номер шага, параметр и ошибку. Сравни шаги 0.1, 0.5 и 1.1 на одинаковом количестве итераций. Сначала предположи характер поведения, затем проверь его таблицей.

После этого разберите один шаг линейной модели вручную и сравните с ноутбуком. Запусти несколько десятков шагов с малым шагом, сохрани параметры и проверь предсказание в отдельном вызове. Одного уменьшения ошибки недостаточно для доказательства качества на новых данных, но оно помогает проверить механизм обучения.

## Самостоятельная работа P08-HW01

Для x = [0,1], y = [2,5], начальных w = 0 и b = 0 вычисли MSE, обе производные и один одновременный шаг с learning rate = 0.1. Покажи новые предсказания и новую ошибку. Затем реализуй цикл и сравни его результат с простой функцией 3x+2, которую можно вывести из этой учебной таблицы.

Отдельно объясни три наблюдения: ошибка не меняется; ошибка быстро растёт; ошибка уменьшается на train, но ухудшается на отложенных данных. Не своди все три случая к рекомендации «увеличить количество итераций»: причины и проверяемые гипотезы различаются.

## Подсказки и критерии

Подсказка 1: выпиши остатки для старых параметров. Подсказка 2: рассчитай два средних отдельно и проверь множитель 2. Подсказка 3: сравни аналитический градиент с численным, меняя только один параметр.

Критические ошибки — перепутать знак обновления, подменить градиент значением loss или использовать разные состояния параметров в одном одновременном шаге. Арифметику допускается исправить, но смысл изменения должен быть объяснён самостоятельно.

Новая попытка: x = [0,1], y = [1,3], шаг 0.1, начальные параметры нулевые. Отложенная проверка будет содержать признак другого масштаба. Нужно предсказать, почему прежний learning rate может перестать работать, и подтвердить гипотезу экспериментом.

Дополнительное объяснение: [Google Gradient descent](https://developers.google.com/machine-learning/crash-course/linear-regression/gradient-descent). О влиянии шага: [Google Hyperparameters](https://developers.google.com/machine-learning/crash-course/linear-regression/hyperparameters).
