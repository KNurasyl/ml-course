## Проверь себя сначала

**Короткий путь для знакомой темы, 2–5 минут.** Для f(x) = x² − 4x найди производную в x = 3 точно и центральной разностью с h = 0.1. В какую сторону немного сдвинуть x, чтобы f уменьшилась?

Всё верно и объяснение совпадает по смыслу — переходи сразу к самостоятельной работе P07-HW01, затем к новому варианту. Ошибка, сомнение или ответ без объяснения — проходи урок полностью с начала. [Как работает адаптивный маршрут](../self-study.md#адаптивный-маршрут).

## От конечного изменения к локальному

Для f(x) = x² значение при x = 2 равно 4. При x = 2.01 оно равно 4.0401. Вход увеличился на 0.01, выход — на 0.0401. Отношение этих изменений равно 4.01. Оно показывает среднюю скорость изменения на маленьком отрезке. Если шаг уменьшать, для этой функции отношение приближается к 4.

Производная описывает локальную скорость изменения. Для квадрата она равна 2x, поэтому в точке 2 получается 4. Важен смысл: рядом с этой точкой небольшое положительное изменение входа примерно умножается на четыре в изменении выхода. Это приближение для малого шага, а не точная формула разности на произвольном расстоянии.

Можно увидеть правило без заучивания. Разность (x+h)² − x² равна 2xh + h². После деления на h остаётся 2x + h. При стремлении h к нулю добавка исчезает. Здесь h не должен быть равен нулю во время обычного деления; речь о предельном поведении выражения.

## Численная проверка

Односторонняя разность использует f(x+h) и f(x). Центральная использует f(x+h) и f(x−h), деля разность на 2h. Для квадрата в точной арифметике центральная формула даёт 2x при любом ненулевом h. На компьютере появляются ошибки округления, поэтому слишком маленький h не обязательно улучшает результат.

В ноутбуке сравни аналитическое значение 4 с численной оценкой при x = 2 и h = 0.00001. Разницу нужно оценивать с разумной погрешностью, а не требовать побитового совпадения. Если функция другая, конечная разность дополнительно содержит ошибку приближения. Поэтому численная проверка — полезный диагностический инструмент, а не универсальная замена математическому выводу.

## Производная функции ошибки

Теперь возьмём L(w) = (w−3)². Это учебная ошибка, минимальная при w = 3. Её производная равна 2(w−3). При w = 1 знак отрицательный: небольшой шаг вправо уменьшает ошибку. При w = 4 знак положительный: уменьшение w помогает двигаться к минимуму. Именно направление изменения понадобится в градиентном спуске.

Если параметров два, можно менять один, временно удерживая другой постоянным. Получается частная производная. Для e = wx+b−y производная e² по w равна 2e×x, а по b — 2e. В первом случае изменение w проходит через множитель x; во втором b добавляется непосредственно. Усреднение таких выражений по примерам даёт частные производные средней ошибки.

## Практика с поддержкой

Вычисли f(2), f(2.01) и отношение приращений вручную. Затем повтори вычисления кодом для нескольких шагов. Нарисуй небольшой график или таблицу, где видно уменьшение разницы с аналитическим ответом. Для L(w) проверь точки 1, 3 и 4 и объясни знак производной словами.

## Самостоятельная работа P07-HW01

Для g(t) = (t+1)² найди производную в точке t = 2, оцени её центральной разностью и объясни, куда нужно немного сдвинуть t, чтобы уменьшить g. Затем проверь производные e² по w и b для одного примера x = 2, y = 5 при w = 1, b = 0.

Сохрани вычисления, код проверки, выбранный шаг и объяснение допустимой разницы. Если вывод формулы пока не даётся, отметь это отдельно: правильный ответ, полученный только численной функцией, ещё не подтверждает понимания цепочки зависимостей.

## Подсказки и оценка

Подсказка 1: сначала посчитай остаток e. Подсказка 2: выпиши, через какой множитель меняемый параметр влияет на e. Подсказка 3: измени только один параметр небольшим шагом и сравни знак наблюдаемого изменения с формулой.

Работа принимается, если формула, численная проверка и объяснение направления согласованы. Критическая ошибка — считать значение функции её производной или менять сразу оба параметра при проверке одной частной производной.

Новая попытка использует h(t) = (t−2)² в точке 0. Через интервал восстанови производные средней ошибки линейной модели без готовой подсказки. Источник для связи с обучением: [Google Gradient descent](https://developers.google.com/machine-learning/crash-course/linear-regression/gradient-descent).
