## Значение и форма

Вектор — упорядоченный набор чисел. В ML его элементы часто описывают разные признаки одного объекта. Порядок важен: перестановка колонок при неизменных весах меняет смысл вычисления. Матрица может собирать несколько объектов строками, а признаки — колонками. Но это соглашение конкретной задачи: матрица сама по себе не сообщает, что в ней считается объектом.

Форма массива описывает количество элементов вдоль каждой оси. Для таблицы из двух строк и трёх колонок форма равна (2,3). Вектор из трёх весов имеет форму (3,). Строка (1,3), столбец (3,1) и одномерный массив (3,) содержат одинаковое количество чисел, но ведут себя не одинаково при операциях. Поэтому первым шагом отладки часто становится проверка shape, а не изменение формул наугад.

Скалярное произведение двух одинаково длинных векторов умножает соответствующие элементы и складывает произведения. Для [1,2] и [3,4] получается 1×3 + 2×4 = 11. Это взвешенная сумма. Если признаки описывают объект, а второй вектор содержит веса, результат может быть частью предсказания линейной модели.

## Разобранное матричное вычисление

Возьмём X с двумя строками [1,2,3] и [4,5,6]. Вектор w равен [1,0,−1]. Первая строка даёт 1×1 + 2×0 + 3×(−1) = −2. Вторая даёт 4×1 + 5×0 + 6×(−1) = −2. Результат X @ w — вектор [-2,−2] формы (2,).

Внутренние размеры должны совпадать: три колонки X соответствуют трём весам. Матрицу формы (2,3) нельзя так же умножить на вектор формы (2,): неизвестно, с чем сопоставить третий признак. Поэлементное умножение и матричное произведение — разные операции. В NumPy символ * обычно выполняет поэлементное действие, а @ — матричное произведение.

Если добавить одно число b ко всем двум результатам, NumPy применит broadcasting. Это удобно, но может скрывать ошибку. Например, вычитание массива формы (2,1) из массива формы (2,) может создать таблицу (2,2), хотя ты ожидал два остатка. Код выполнится, но посчитает другую задачу.

## Подсказки и оценивание

Подсказка 1: подпиши смысл каждой оси. Подсказка 2: выпиши скалярное произведение для одной строки. Подсказка 3: проверь соответствие «номер колонки — номер веса» после перестановки.

Критическая ошибка — получать правильные числа только на одном примере, не понимая появившуюся лишнюю ось. Работа подтверждает навык, если ты объясняешь размеры, различаешь операции и проверяешь результат независимым ручным расчётом.

Для повторной попытки используй строки [1,1] и [2,−1], веса [3,2], b = 0. Через интервал вернись к матричному вычислению в линейном слое нейросети: механизм тот же, меняется количество объектов и параметров.
