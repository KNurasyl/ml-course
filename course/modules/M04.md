# M04. Вероятность и статистика

Модуль содержит пять самостоятельных уроков, локальную практику, итоговую домашнюю работу и отдельные ключи. Материалы подготовлены; результаты ученика остаются в личном журнале. Все обязательные вычисления этого модуля выполняются на CPU в окружении курса.

## Порядок уроков

1. [M04-L01. Случайность и условие](../lessons/M04-L01.md) — Вычислить условную вероятность по таблице и явно назвать знаменатель.
2. [M04-L02. Среднее, дисперсия и выборка](../lessons/M04-L02.md) — Различить разброс наблюдений и неопределённость среднего, вычислить обе величины.
3. [M04-L03. Неопределённость метрики](../lessons/M04-L03.md) — Оценить неопределённость доли успехов и корректно интерпретировать интервал.
4. [M04-L04. Bootstrap и интервалы](../lessons/M04-L04.md) — Построить парный bootstrap и сохранить правильную единицу пересэмплирования.
5. [M04-L05. Гипотезы и эксперимент](../lessons/M04-L05.md) — Различить размер эффекта, статистическую проверку и решение о полезности изменения.

## Практическая лабораторная

[Инструкция и проверенный запуск](../../labs/M04/README.md). Пример воспроизводит ключевые вычисления, а домашняя работа меняет условия. Не нужно угадывать результат по чужому выводу: сначала запиши ожидание и затем сравни с измерением.

## Домашняя работа M04-HW01

Даны оценки на восьми независимых сессиях: A=[1, 0, 1, 0, 1, 0, 1, 0], B=[1, 1, 1, 0, 1, 1, 1, 0]. Вычисли доли, парные разности и эффект B−A. Построй 95%-процентильный bootstrap-интервал по 20000 повторам seed42. Посчитай знаковый тест на нетождественных парах. Сформулируй ограничения малого набора и следующий заранее зафиксированный эксперимент.

Сохрани код, короткий отчёт, промежуточные расчёты и условия воспроизведения. Обязателен хотя бы один вывод о границе результата: на какие новые случаи он пока не распространяется.

## Рубрика

1. Доли и эффект соответствуют парам.
2. Пересэмплируются пары, а не независимые стороны.
3. Ничьи исключены с явным указанием оставшегося числа пар.
4. Интервал и p-value интерпретированы корректно.
5. Следующий эксперимент имеет основную метрику и правило остановки.

Критические ошибки: назвать повторы новыми сессиями, подменить p вероятностью гипотезы, неотклонение считать равенством.

Каждый критерий оценивается отдельно. После содержательной подсказки отметь «с поддержкой» и выполни новый вариант. Итоговая цифра не компенсирует критическую ошибку. Зачёт здесь — собственная проверка по рубрике; профессиональный грейд и независимое подтверждение навыка отдельно не присваиваются.

## Новая попытка и проверка позже

Возьми A=[0, 0, 1, 1, 0, 1], B=[1, 0, 1, 0, 1, 1]. Пересчитай эффект и победы/поражения. Через 3–7 дней объясни разницу между стандартным отклонением, стандартной ошибкой и доверительным интервалом.
