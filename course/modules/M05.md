# M05. Классический ML

Модуль содержит пять самостоятельных уроков, локальную практику, итоговую домашнюю работу и отдельные ключи. Материалы подготовлены; результаты ученика остаются в личном журнале. Все обязательные вычисления этого модуля выполняются на CPU в окружении курса.

## Порядок уроков

1. [M05-L01. Задача и исходное решение](../lessons/M05-L01.md) — Сформулировать задачу классификации, построить baseline и выбрать метрику по ошибкам.
2. [M05-L02. Линейные модели](../lessons/M05-L02.md) — Объяснить логистическую модель, вероятность и порог как разные части решения.
3. [M05-L03. Деревья и бустинг](../lessons/M05-L03.md) — Построить простое дерево, объяснить усреднение в листьях и идею бустинга.
4. [M05-L04. Валидация и утечки](../lessons/M05-L04.md) — Организовать cross-validation с подготовкой внутри каждого fold и отдельным финальным test.
5. [M05-L05. Анализ ошибок](../lessons/M05-L05.md) — Разобрать ошибки по содержательным группам и выбрать следующий эксперимент без подгонки теста.

## Домашняя работа M05-HW01

Собери регрессионный эксперимент на синтетическом наборе x из равномерного распределения[−3, 3], y=x²+шум Normal(0, 0.2). Используй seed42, 180train, 60validation, 60test. Сравни среднее train, LinearRegression, DecisionTreeRegressor глубин 2 и 4, GradientBoostingRegressor с 60 деревьями глубины 2. Выбирай по validation-MAE, затем один раз измерь test. Сохрани версии, разбиение, таблицу метрик и срезы x<0/x≥0. Отдельно вычисли точный разбор: y=[0, 1, 4, 9], baseline=[2, 2, 2, 2], candidate=[0, 2, 3, 8].

Сохрани код, короткий отчёт, промежуточные расчёты и условия воспроизведения. Обязателен хотя бы один вывод о границе результата: на какие новые случаи он пока не распространяется.

## Рубрика

1. Разделение выполнено до выбора модели.
2. Baseline обучен только на train.
3. Настройки выбираются по validation, а test показан после выбора.
4. Приведены MAE, MSE и размер срезов;сохранены реальные измерения.
5. Вывод ограничен синтетической задачей и не выдаёт её за качество интервьюера.

Критические ошибки:выбор лучшего по test, утечка целевой переменной, подмена отчёта заранее ожидаемым победителем.

Каждый критерий оценивается отдельно. После содержательной подсказки отметь «с поддержкой» и выполни новый вариант. Итоговая цифра не компенсирует критическую ошибку. Зачёт здесь — собственная проверка по рубрике; профессиональный грейд и независимое подтверждение навыка отдельно не присваиваются.

## Новая попытка и проверка позже

Замени закон на y=2x+1+шум с тем же разбиением. Заново сравни модели и объясни, почему преимущество бустинга не универсально. Через 3–7 дней защити выбор baseline, split и метрики без открытия конспекта.
