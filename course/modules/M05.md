## Домашняя работа M05-HW01

Проведи самостоятельный классификационный эксперимент на exercises/M05/data/hw.csv. Сначала реализуй starter и пройди checker. Границы времени: train day<144, validation144…191, test≥192; группы, пересекающие границы, исключаются целиком и перечисляются. Используй только experience_years,answer_words,track. Сравни baseline train-prior и LogisticRegression C=[.1,1,10]; порог [.25,.5,.75] выбирай по (2FN+FP)/N на validation. При ничьей меньше log loss, затем C и порог. До открытия test сохрани выбор. Сохрани полный pipeline и порог, восстанови в новом процессе, оцени test и срез неизвестной категории. Подмени future-столбец и докажи отсутствие влияния. Не используй готовый demo-набор как сдачу.

[Стартовый файл, контракт и команда проверки](../../exercises/M05/README.md). Сохрани свой код, промежуточные результаты и объяснение в submissions/M05-HW01/. Проверки поведения не оценивают понимание: объясни каждое выбранное ограничение без открытого ключа.

## Рубрика

1. Разрешённые признаки обоснованы моментом доступности; будущий столбец исключён.
2. Split одновременно сохраняет группы и время; исключённые группы перечислены.
3. Imputer, scaler, encoder и classifier обучены только на train; журнал fit это подтверждает.
4. C и порог выбраны только по validation; все кандидаты и правило ничьих сохранены до test.
5. Есть baseline, матрица ошибок, стоимость, log loss и размер каждого среза.
6. Артефакт восстанавливается в новом процессе; пропуск/неизвестная категория/неполная схема обработаны по контракту.
7. Самостоятельно объяснён новый вариант с другой ценой ошибки и границей времени.

Все семь условий обязательны. Критические ошибки: fit/выбор по test, утечка будущего признака, пересечение групп, выдуманные измерения. Успешный запуск эталона не засчитывает самостоятельную работу.
