# M09. Применение и запуск LLM

Модуль запускает настоящую компактную LLM на CPU и учит управлять её входом, ресурсами и ошибками. Обязательная модель SmolLM2-135M-Instruct закреплена на конкретной ревизии; скачивание, измерения и настоящее сравнение float32/int8 разделены на проверяемые этапы. Качество русскоязычного интервью не предполагается заранее.

## M09-HW01 — самостоятельная работа

Подготовь 5 запросов: определение SQL транзакции, уточнение неполного ответа, просьба вернуть JSON, неоднозначная реплика и русский технический вопрос. Запусти закреплённую модель, сохрани messages, фактический template, число токенов, настройки, время загрузки и generate. Для sampling выполни заранее выбранное число повторов, не удаляя неудачные.

Реализуй проверку контекста и контракт feedback/score. Добавь тесты пустого вывода, boolean score, лишнего ключа, оборванного JSON и превышения бюджета. Составь отчёт, где фактические измерения отделены от оценок памяти и желательных порогов. Русский ответ оцени отдельно, не переноси результат английского вопроса на другой язык.

## Рубрика

По каждому пункту поставь 0 — отсутствует/неверно, 1 — частично или после существенной помощи, 2 — полностью и самостоятельно. Все пункты обязательны; для зачёта самопроверки нужно 2 по каждому, затем отдельный перенос на новый случай.

- Пять запросов и все outputs сохранены с моделью, ревизией и настройками.
- Фактический template и бюджет контекста проверены.
- Измерения времени и памяти подписаны корректно; ограничения русского качества указаны.
- Валидатор и конечный fallback проверены на всех отказных случаях.

Критические ошибки: Утверждение, что сохранённая история всегда целиком известна модели., Обещание качества или скорости без локального измерения. При любой из них работа возвращается на исправление независимо от суммы баллов. Правильный код с неверным объяснением проверяет только запуск, но не понимание. Помощь отметь отдельно от правильности.

## Новая попытка и отложенная проверка

**M09-HW01-B.** C=768, обязательная часть после шаблона=420 токенов, история=200, резерв=128. Новое уточнение добавляет 60 токенов. Старейшая полная пара истории занимает 80, её можно удалить. Вычисли бюджет до/после уточнения и удаления. Затем первый ответ не является JSON, второй завершился timeout; политика допускает максимум 2 попытки. Опиши конечный ответ пользователю, значение score и число новых запросов к модели.

**M09-HW01-C — через 7–10 дней.** Текущий ход 48. Ответ A имеет turn_id=47 и корректный JSON {feedback:«Уточни пример»,score:1}. Ответ B имеет turn_id=48 и JSON {feedback:«Ошибка сервиса»,score:true}. Доступных повторов больше нет. Для каждого укажи причину отказа и действие, затем объясни, почему fallback со score=0 был бы неверным выводом о кандидате.

Ответь без открытого ключа, затем сравни с разделом M09-HW01: B и C в решениях. Зафиксируй помощь и фактически обнаруженную ошибку. Отложенный статус не присваивается заранее.
