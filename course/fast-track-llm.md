# Быстрый вход в M09–M11 для тех, кто уже делал RAG

**Расширение 1.2.0.** Страница меняет порядок работы внутри модулей M09–M11 и не входит в обязательный минимум 1.1.0. Уроки модулей не сокращены и не заменены: быстрый вход только решает, какие из них читать, по результату твоей собственной работы.

## Кому подходит

Тому, кто уже собирал в работе RAG-системы или интеграции LLM: писал промпты и шаблоны сообщений, подключал поиск, разбирал неудачные ответы модели. Это про [профиль ученика](references/methodology.md#профиль-ученика). Если такого опыта нет, проходи модули по порядку оглавления: быстрый вход рассчитан на того, кому подробные разборы знакомых вещей мешают.

Быстрый вход не отменяет зависимостей программы. M08 (токены, attention, контекст) нужен до M09: на нём держатся бюджет контекста и шаблоны диалога. Модули идут по порядку M09 → M10 → M11: домашняя работа M10 использует навыки M09, а M11 сравнивает версии тренажёра.

## Порядок для одного модуля

1. Прочитай обзор модуля ([M09](modules/M09.md), [M10](modules/M10.md), [M11](modules/M11.md)), запусти лабораторную по её README и выполни контракт из `exercises/Mxx`: стартовый файл и его проверку.
2. Выполни домашнюю работу модуля (M09-HW01, M10-HW01, M11-HW01) без чтения уроков. Сохрани всё, что требует условие: запросы, outputs, настройки, измерения. Неудачные генерации не удаляй.
3. Оцени себя по рубрике модуля: 0 — нет или неверно, 1 — частично или после существенной помощи, 2 — полностью и самостоятельно. Отдельно проверь критические ошибки модуля.
4. Каждый пункт ниже 2 — уроки из таблицы ниже: прочитай, выполни самостоятельную задачу урока, затем исправь соответствующую часть домашней работы и оцени её заново.
5. Любая критическая ошибка — весь модуль по порядку: ошибка такого рода говорит о пробеле в модели понятий, а не в одной детали.
6. Все пункты на 2 и нет критических ошибок — выполни HW-B, а через 7–10 дней HW-C, как в обычном маршруте. Быстрый вход экономит чтение, но навык засчитывают только новый вариант B, отложенный C и отсутствие критических ошибок.
7. В [журнале](../progress/progress.md) отметь «быстрый вход», оценки по пунктам рубрики и уроки, к которым пришлось вернуться.

[M10-L06](lessons/M10-L06.md) рекомендуется прочитать в любом случае. В нём русский диагностический корпус и сохранённый отрицательный результат английского энкодера: опыт RAG на английских данных не переносится на русский язык автоматически.

## Почему так

Для того, кто тему уже знает, решение задачи полезнее изучения подробного разобранного примера (Kalyuga et al., 2001; эффект обратной экспертизы — Kalyuga et al., 2003). Домашняя работа модуля — самая полная задача, поэтому она и служит диагностикой, а рубрика показывает, какой именно пробел закрывать. Подробности и источники — в [исследовании для версии 1.2.0](../quality/research-2026-11-03.md), раздел 4. Для тем M00–M06 тот же принцип работает через блоки «Проверь себя сначала» ([адаптивный маршрут](self-study.md#адаптивный-маршрут)).
