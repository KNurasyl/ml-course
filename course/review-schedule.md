# Расписание повторения

**Расширение 1.2.0.** Правило дополняет [отложенную проверку](self-study.md#отложенная-проверка) из учебного цикла: даты повторений считаются по журналу, а сами повторения смешивают задачи разных модулей.

## Правило 1–3–7–21

Ступени отсчитываются от первой самостоятельной попытки по уроку — состояние «Самостоятельно — самооценка» или «Подтверждено позже — самооценка».

| Событие | Следующая проверка | Ступень |
| --- | --- | --- |
| Первая самостоятельная попытка | через 1 день | 1 |
| Успешная проверка на ступени 1 | через 3 дня | 2 |
| Успешная проверка на ступени 2 | через 7 дней | 3 |
| Успешная проверка на ступени 3 | через 21 день | 4 |
| Успешная проверка на ступени 4 | повторений больше не назначается | пройдены все четыре |
| «С поддержкой» или «Не проверено» | на следующий день | не меняется |
| «Требуется повторение» | на следующий день | сбрасывается в 0 |

Пример: самостоятельная попытка 10 ноября. Если каждая проверка проходит в свой день и успешно, следующие даты — 11 ноября, 14 ноября, 21 ноября и 12 декабря. Пропущенная дата не сдвигает правило: проверка просто остаётся в списке, пока не будет выполнена.

Пройденные четыре ступени — устойчивый результат самопроверки, а не внешнее подтверждение навыка. Внешнюю проверку журнал хранит отдельным полем.

## Что считается проверкой

- Новый вариант B или отложенный C урока, решённый без подсказок.
- Задача следующего урока, которая использует то же умение.
- Карточка урока из [шпаргалки](cheatsheet.md): сначала восстанови правило, смысл величин и главную ошибку сам, затем сверься.

Перечитать решение или перезапустить эталон — не проверка: это узнавание, а не воспроизведение.

## Смешанный сеанс

Не повторяй накопившиеся темы по одной. Возьми за один сеанс 2–3 задачи из разных модулей: дашборд раскладывает повторения по очереди из разных модулей. Чередование тем труднее, чем блок из одной темы, но знания после него устойчивее; распределённое повторение и проверка по памяти относятся к самым полезным приёмам самообучения (Dunlosky et al., 2013; Roediger & Karpicke, 2006). Подробности — в [исследовании для версии 1.2.0](../quality/research-2026-11-03.md), раздел 4.

## Как вести журнал

Текст размышлений остаётся в [журнале](../progress/progress.md). Попытку, по которой считаются даты, добавь командой из корня курса:

```powershell
.\.venv\Scripts\python.exe tools\progress.py add M02-L01-A --min 45 --self 3 --help none --route short
.\.venv\Scripts\python.exe tools\progress.py due
.\.venv\Scripts\python.exe tools\progress.py dashboard
```

`--self`: 0 — не проверено, 1 — требуется повторение, 2 — с поддержкой, 3 — самостоятельно, 4 — подтверждено позже. `--help`: none, hint1–hint3, key (полный ключ), external. `--route`: short — короткий путь после «Проверь себя сначала» или быстрого входа, full — полный урок. Если ты уже заполнил строки в progress.md, перенеси их командой `tools\progress.py import`: она берёт только строки с датой и не создаёт повторов.

Команда `due` показывает повторения на сегодня, сгруппированные в смешанные сеансы. Все даты и сводка по модулям собираются на странице [дашборда прогресса](../progress/dashboard.md).
