# Ключи решений для самопроверки

Ключи для самостоятельной проверки после собственной попытки. Эталон не означает, что ученик уже выполнил работу. Сначала сохранить первую попытку; после просмотра полного решения назначить новый случай. Численные значения проверены отдельными расчётами, но объяснение и перенос оцениваются по реальному ответу ученика.

## Ключи входной диагностики D00

1. f(3) = 7; из 2x + 1 = 9 следует x = 4. Требовать понимания подстановки и обратного преобразования, а не только два числа.

2. Увеличение b на 2 сдвигает все значения y вверх на 2. Изменение w с 1 до 2 увеличивает y на x: при положительном x значение растёт, при отрицательном уменьшается, при нуле не меняется.

3. Среднее равно 4, медиана равна 2. Большое значение 8 влияет на среднее сильнее; медиана определяется центральным элементом упорядоченной последовательности.

4. log₂(8) = 3, поскольку 2³ = 8.

5. 1×3 + 2×4 = 11. Поэлементное произведение [3,8] — промежуточный результат, но не скалярное произведение.

6. Результат имеет форму 2×1. Внутренние размеры 3 и 3 совпадают. Умножение 2×3 на 2×1 в таком порядке не определено.

7. Значения 4 и 4.0401; приращение 0.0401; отношение 4.01. Это средняя скорость изменения на малом отрезке, близкая к производной 4 в точке 2.

8. Обе доли равны 0.8. При сопоставимом способе получения и независимости наблюдений большая выборка обычно даёт меньшую случайную неопределённость. Смещение отбора или сильная зависимость наблюдений не исправляются одним увеличением количества строк. Формальные интервалы здесь ещё не обязательны.

9. Результат 14/3, около 4.666666667. Требуется сначала возвести каждую ошибку в квадрат, затем усреднить; ошибочные входы отвергать явно. Пустой набор нельзя объявлять нулевой ошибкой.

10. Результат [-2,−2], форма (2,) при одномерном w. При явном столбце формы (3,1) результат будет (2,1); принять это объяснение, если представление обозначено.

11. Единственного рисунка нет. Минимальные признаки корректности: путь вход → проверка → обработка → ответ; явно отмеченное состояние; конкретный отказ и действие при нём. Не оценивать количество модных компонентов.

12. Рабочее объяснение: параметры или обучаемая структура подбираются по данным относительно цели; инференс применяет выбранную модель. Первичное незнание этой темы не является причиной отказа от курса.

## Общие правила оценивания

По каждому результату отдельно фиксировать состояние: не проверено, требуется повторение, с поддержкой, самостоятельно, подтверждено позже. Технический запуск не присваивает состояние ученику. Не считать правильное переписывание эталона самостоятельным решением.

Для простых целых вычислений требовать точный результат. Для центральных разностей использовать абсолютную погрешность 0.000001. Для метрик детерминированного эксперимента P09–P10 в закреплённом окружении ориентир 0.00000001. При другой библиотечной реализации сначала объяснить причину численной разницы, не подменять смысл работы механическим сравнением строк.

## P05

Откат означает возврат согласованного предыдущего артефакта, включая параметры и преобразования. При несовместимой нормализации возможен неверный ответ без исключения. Подходящая проверка — сопоставить версию преобразования и модели и выполнить известный сквозной пример перед переключением.

Принять разные архитектурные рисунки при наличии проверяемого пути запроса и отделённого процесса обучения. Фраза «будем мониторить» без сигнала и действия недостаточна.

## P06

Новый запрос меняет вход/контекст текущего вызова; сам по себе не обучает параметры. Сохранение переписки меняет состояние приложения, но не обязательно контекст следующего вызова. Добавление найденного фрагмента меняет контекст. Загрузка методички меняет документы/индекс; на ответ она влияет после соответствующего поиска и передачи.

Обучение адаптера меняет обучаемые параметры адаптера; базовые веса могут оставаться замороженными. Изменение системной инструкции меняет вход вызова при прежних весах. Не требовать, чтобы ученик называл изменение всех весов обязательным признаком fine-tuning.

Если забыта ранняя реплика, сначала проверить сформированный контекст и извлечение истории. При устаревшей методичке проверить корпус, версию индекса и найденный фрагмент. Критическая ошибка — автоматически считать любой разговор дообучением.

Повторный случай с резюме истории: исходный архив остаётся в приложении; модель получает резюме, которое может потерять детали. Параметры от такого пересказа сами по себе не обновляются.

## Проверка самой рубрики

1. Верное новое решение и самостоятельное объяснение: состояние «самостоятельно».

2. Верное решение после указания формулы: «с поддержкой»; назначить другой случай.

3. Работающий код при утверждении «каждый запрос обучает веса»: понимание модели требует повторения.

4. Высокая метрика после подбора по test: эксперимент требует исправления.

5. Хороший отчёт без данных сравнения: вывод не подтверждён.

6. Корректно обнаруженный ресурсный предел с воспроизводимым измерением: инженерное умение может быть подтверждено, требование большого запуска отдельно не выполнено.

7. Старое решение не работает в новых условиях, ученик выявил причину и проверил исправление: перенос может быть подтверждён по новому результату, а не по первой неудачной попытке.
