## M04-L01-A01

P(correct|technical)=42/60=0.7. P(technical|correct)=42/74≈0.567568. Общая доля 74/100=0.74. При новом составе 0.2·0.8+0.8·0.7=0.72. При равных долях 0.75. Будущий расчёт предполагает неизменность качества внутри типов.

```python
assert 42/60==.7
assert (32+42)/100==.74
assert abs(.2*.8+.8*.7-.72)<1e-12
```


## M04-L02-A01

Среднее 5, квадраты отклонений 9, 1, 1, 9, сумма 20. s²=20/3≈6.6667, s≈2.58199, SE≈1.29099. Копии не создают независимых наблюдений, уменьшение SE будет ложным. В повторном примере оба средних равны 5, но s равны 1 и 5.

```python
import numpy as np
x=np.array([2.,4.,6.,8.])
assert x.mean()==5
assert np.isclose(x.var(ddof=1),20/3)
assert np.isclose(x.std(ddof=1)/2,np.sqrt(5/3))
```


## M04-L03-A01

Доли 0.9. SE≈0.067082 и 0.021213. Уилсон даёт приблизительно [0.69897, 0.97213] и [0.85059, 0.93433]. Больший независимый набор оценивает вероятность точнее. Это не гарантия доли в следующей конечной партии. Для 20/20 нижняя граница≈0.838875, верхняя 1.

```python
from math import sqrt

```


## M04-L04-A01

Разности [1, 0, 1, 0], средняя 0.5. Для [0, 0, 2, 3] получаем [1, 1, 1, 0], средняя 0.75. При seed42 и 20000 повторах интервал [0, 1]. Набор слишком мал для узкого вывода.

```python
import numpy as np
d=np.array([1.,0.,1.,0.]);rng=np.random.default_rng(42)
means=d[rng.integers(0,4,size=(20000,4))].mean(1)
assert np.allclose(np.quantile(means,[.025,.975]),[0,1])
assert d[[0,0,2,3]].mean()==.75
```

При группах выбираются люди с возвращением и переносятся обе строки. Способ усреднения заранее определяет равный вес людей или ответов.

## M04-L05-A01

Для 7/8 p=18/256=0.0703125. H₀ не отклоняется на уровне 0.05; равенство не доказано. Для 8/8 p=2/256=0.0078125. Пример протокола: основная метрика — доля корректной обратной связи по фиксированной рубрике, минимальный полезный прирост 5 п.п., одинаковые новые независимые сессии, фиксированный объём до анализа, ограничения по ошибочным советам и задержке. Объём нужно обосновать ожидаемым шумом и мощностью, а не выбрать после результата.

```python
assert 18/256==.0703125
assert 2/256==.0078125
```
