## M04-L02-A01

Среднее 5, квадраты отклонений 9, 1, 1, 9, сумма 20. s²=20/3≈6.6667, s≈2.58199, SE≈1.29099. Копии не создают независимых наблюдений, уменьшение SE будет ложным. В повторном примере оба средних равны 5, но s равны 1 и 5.

```python
import numpy as np
x=np.array([2.,4.,6.,8.])
assert x.mean()==5
assert np.isclose(x.var(ddof=1),20/3)
assert np.isclose(x.std(ddof=1)/2,np.sqrt(5/3))
```

## M04-L04-A01

Разности [1, 0, 1, 0], средняя 0.5. Для [0, 0, 2, 3] получаем [1, 1, 1, 0], средняя 0.75. При seed42 и 20000 повторах интервал [0, 1]. Набор слишком мал для узкого вывода.

```python
import numpy as np
d=np.array([1.,0.,1.,0.]);rng=np.random.default_rng(42)
means=d[rng.integers(0,4,size=(20000,4))].mean(1)
assert np.allclose(np.quantile(means,[.025,.975]),[0,1])
assert d[[0,0,2,3]].mean()==.75
```

При группах выбираются люди с возвращением и переносятся обе строки. Способ усреднения заранее определяет равный вес людей или ответов.

## M04-L05-A01

Для 7/8 p=18/256=0.0703125. H₀ не отклоняется на уровне 0.05; равенство не доказано. Для 8/8 p=2/256=0.0078125. Пример протокола: основная метрика — доля корректной обратной связи по фиксированной рубрике, минимальный полезный прирост 5 п.п., одинаковые новые независимые сессии, фиксированный объём до анализа, ограничения по ошибочным советам и задержке. Завершённое планирование объёма — [M04-L08](../../course/lessons/M04-L08.md). Например, при парных предположениях improve=.10,regress=.05, одностороннем sign test α=.05 и мощности≥.8 первый размер из [100,200,400,800] —400 по точному расчёту. Это предположение переходов, а не следствие одного среднего прироста; при неизвестной доле регрессий нужен анализ чувствительности.

```python
assert 18/256==.0703125
assert 2/256==.0078125
```

## M04-L06-A

Вероятности фактических исходов [0.75,0.75,0.1]. Потери [0.2876820725,0.2876820725,2.3025850930], среднее **0.9593164126**. Третий вклад наибольший. При p→0 справа −ln(p) неограниченно растёт; ln(0) не является нулём. Для данной функции можно явно отвергать p≤0 и p≥1, если контракт ограничен открытым интервалом, либо отдельно обрабатывать допустимые граничные случаи при вероятности фактического события 1. Вероятность за [0,1] всегда недопустима. Нельзя молча заменить невалидный вход «хорошей» потерей.

## M04-L08-C
