## M01-L01-A01

## M01-L03-A01

Train содержит пять строк A, A, A, B, B; validation две C, C; test одну D. Множества {A, B}, {C}, {D} попарно не пересекаются. В случайном разбиении разные сессии A могут оказаться по разные стороны. Это проверяет смесь знакомых и новых людей, а не заявленный сценарий.

```python
groups={"train":{"A","B"},"validation":{"C"},"test":{"D"}}
assert not groups["train"]&groups["validation"]
assert not groups["train"]&groups["test"]
assert not groups["validation"]&groups["test"]
```

Для будущих сессий знакомых людей допустимо обучение на январе–феврале и проверка на марте–апреле, если все признаки рассчитаны только из доступного прошлого. Для новых компаний потребуется группировка по компании, возможно совместно с временем.

## M01-L04-A01

Среднее по сессиям (5+15+40)/3=20. Среднее по строкам JOIN (5+5+15+40)/4=16.25. Корректный запрос:

```sql
SELECT s.id, s.seconds, COALESCE(a.n,0) AS answer_count
FROM sessions s
LEFT JOIN (SELECT sid,COUNT(*) AS n FROM answers GROUP BY sid) a
ON a.sid=s.id;
```

Ожидаются (a, 5, 2), (b, 15, 1), (c, 40, 1). Проверка: COUNT(*)=COUNT(DISTINCT id)=3. В повторном варианте две сессии по 10 секунд остаются двумя сущностями; DISTINCT seconds возвращает лишь одно число и не сохраняет идентичность.

## M01-L05-A01

μ=(1+3+5+7)/4=4. Train после центрирования [−3, −1, 1, 3], test [5, 9], новый объект 11 даёт 7.

```python
import numpy as np
train=np.array([1.,3.,5.,7.]); test=np.array([9.,13.])
artifact={"mean":float(train.mean()),"feature":"seconds","version":"center-v1"}
snapshot=artifact.copy()
assert np.allclose(train-artifact["mean"],[-3,-1,1,3])
assert np.allclose(test-artifact["mean"],[5,9])
assert 11-artifact["mean"]==7 and artifact==snapshot
```

В повторном варианте μ=0, поэтому test остаётся [10]. Ненулевое среднее теста само по себе не ошибка подготовки.
