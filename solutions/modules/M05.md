## M05-L04-A01

Folds: validationA/trainB, C;validationB/trainA, C;validationC/trainA, B. Правильное среднее(1+3+5+7)/4=4. Глобальное(1+3+5+7+100+102)/6=218/6≈36.3333. Validation после правильного центрирования[96, 98]. StandardScaler находится первым шагом Pipeline, fit вызывается внутри каждого fold. Для новой компании нужна проверка с группировкой по компании.

```python
import numpy as np
train=np.array([1.,3.,5.,7.]);validation=np.array([100.,102.])
assert train.mean()==4
assert np.allclose(validation-train.mean(),[96,98])

```


## M05-L05-A01

Остатки[1, 1, −3, −3], MAE=(1+1+3+3)/4=2, bias=(1+1−3−3)/4=−1. A:MAE=1, bias=1;B:MAE=3, bias=−3. Возможные причины: другой диапазон признаков, ошибочная разметка B, потеря части входа. Различение:ручной аудит исходных записей и сравнение диапазонов на новом наборе. Критерий принятия:снижение MAE на независимых B при заранее допустимом ухудшении A и сохранении критических случаев. После добавления остатка+3 в B, bias=(−3−3+3)/3=−1, MAE=3.

```python
import numpy as np
e=np.array([1.,1.,-3.,-3.])
assert abs(e).mean()==2 and e.mean()==-1
```
