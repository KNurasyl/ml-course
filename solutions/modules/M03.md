## M03-L01-A01

f(5)=9; f′(w)=2(w−2), поэтому f′(5)=6. Прямая разность:((5.1−2)²−9)/0.1=6.1. Небольшое уменьшение 5 снижает функцию. При 1 функция 1, производная−2, движение вправо снижает ошибку. Для(w+1)² при−3 производная−4.

```python
f=lambda w:(w-2)**2
assert f(5)==9
assert abs((f(5.1)-f(5))/.1-6.1)<1e-10
assert f(4.9)<f(5) and f(1.1)<f(1)
```


## M03-L02-A01

ŷ=1·3+1=4, e=−3, L=9. dw=2·(−3)·3=−18, db=−6. При x0 модель равна b, поэтому вес не влияет на потерю, но смещение влияет при b≠y. В повторном варианте ŷ=−1, e=−3, L=9, dw=6, db=−6.

```python
x,y,w,b=3.,7.,1.,1.
L=lambda w,b:(w*x+b-y)**2

```


## M03-L03-A01

Исходная MSE=10. dw=2·(−2−12)/2=−14, db=−6. Новые w=1.7, b=0.3; ответы[2, 5.4], остатки[−1, −1.6], MSE=(1+2.56)/2=1.78. В повторном варианте dw=−10, db=−6, w=1, b=0.6, ответы[0.6, 2.6], MSE=2.96.

```python
import numpy as np
x=np.array([1.,3.]);y=np.array([3.,7.]);w,b=1.,0.
e=w*x+b-y;dw=2*np.mean(e*x);db=2*e.mean()
w,b=w-.05*dw,b-.05*db
assert np.allclose([w,b],[1.7,.3])
assert np.isclose(np.mean((w*x+b-y)**2),1.78)
```
