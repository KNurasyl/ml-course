# M09: решения для самопроверки

Открывай после собственной попытки. Если ты изучил ключ до решения, новая задача из раздела повторения обязательна для проверки самостоятельности. Числа в учебных примерах не являются оценкой реальных кандидатов.

## M09-L01-A

Корректный список: system «You are a backend interview practice assistant. Ask one clarification.»; assistant «What is a SQL transaction?»; user «It is a group of operations.» Затем apply_chat_template(...,add_generation_prompt=True). Передача одного последнего ответа теряет предмет вопроса и этап беседы, поэтому модель может объяснять другой термин или завершить интервью. Для воспроизведения нужны model_id/revision, tokenizer/template, messages, generation config, seed при sampling и версии библиотек. Одного текста результата недостаточно.

## M09-L02-A

Prompt=90+500+260+70+30=950, с резервом1110, превышение86. Удаление120 даёт990 — подходит. Сокращение80 даёт1030 — всё ещё на6выше лимита. Оба действия вместе дают910. Приоритет: сохранить system и текущий вопрос/ответ, удалить старую полную пару120, затем пересчитать настоящие токены с template. Если нужный источник связан с текущим вопросом, удаление истории обычно предпочтительнее, но это должно проверяться на сценариях качества. Числа условны; в реальном коде длины частей не всегда строго аддитивны из-за токенизации границ, поэтому финальная проверка всего prompt обязательна.

## M09-L04-A

Float32:200000000·4=800000000байт=800MB. Int8:200MB без scales/metadata. q=[−3,2,5], восстановление[−0,3;0,2;0,5]. Ошибки[0,04;0,04;0,02], максимум0,04. Эти данные описывают только веса и отдельную операцию округления; реальный процесс дополнительно хранит кеш, буферы, структуры runtime. Скорость зависит от реализации матричных операций и преобразований типов, а не только от числа бит.

## M09-L05-A

Корректный объект принимается на уровне схемы, затем отдельно проверяется смысл. score3 отклоняется по диапазону; true — по точному типу; отсутствиеfeedback — wrong_keys; префикс делает весь текст невалидным JSON. Таймаут возвращает status=unavailable и score=null/отсутствует в отдельной схеме ошибки. Старый ход отбрасывается по generation_id даже при правильной схеме. Политика: одна основная попытка и максимум одна исправляющая в общем лимите времени; затем «Не удалось получить оценку, ответ сохранён, можно повторить». Выбранное число попыток — инженерное решение, проверяемое по задержке и частоте восстановления.

## M09-HW01

Полный исполняемый эталон — labs/M09/demo.py. load_local загружает только локальные файлы pinnedrevision; generate применяет template, проверяет prompt+reserve≤context, запускает greedy и измеряет полный вызов. Отчёт включает parameter_count, parameter_bytes, modelrevision и реальные outputs. validate_feedback отвергает boolean и невалидную схему. Невалидная генерация считается наблюдаемым ограничением маленькой модели, а не поводом подменить output заранее приготовленным ответом.

Ожидаемые защитные результаты: пустая строка→invalid_json; scoretrue→score_out_of_range/typecheck; лишний ключ→wrong_keys; оборванныйJSON→invalid_json; превышение контекста→ValueError до model.generate. Для русского вопроса вручную разбери хотя бы одно утверждение и язык ответа. Если модель не справилась, корректный вывод — данная конфигурация не подходит для этого сценария без дальнейшего сравнения. Синтетический пример памяти200Mfloat32=800MB не заменяет parameter_bytes настоящего запуска; время generate не называетсяTTFT.
