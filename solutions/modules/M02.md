## M02-L01-A01

v−u=(5−1, 2−4)=(4, −2). Смесь=(0.25+3.75, 1+1.5)=(4, 2.5). В общем случае среднее количества может быть дробным: это характеристика набора, а не обещание существования дробной задачи. В повторном варианте среднее (1, 4), разность (4, 4).

```python
import numpy as np
u=np.array([1.,4.]);v=np.array([5.,2.])
assert np.allclose(v-u,[4,-2])
assert np.allclose(.25*u+.75*v,[4,2.5])
```


## M02-L02-A01

u·v=1·2+2·1=4. Обе нормы√5. Разность(−1, 1), расстояние√2. Cosine4/5=0.8. При 3v dot=12, знаменатель=15, cosine=0.8. Нулевой вектор явно отклоняется либо получает специальный статус; здесь выбран ValueError. В повторном варианте cosine=−1, dot=−2, расстояние 2√2.

```python
import numpy as np
u=np.array([1.,2.]);v=np.array([2.,1.])
assert u@v==4 and u@(3*v)==12
assert np.isclose((u@v)/(np.linalg.norm(u)*np.linalg.norm(v)),.8)
assert np.isclose(np.linalg.norm(u-v),np.sqrt(2))
```


## M02-L03-A01

XW=[[1+10, 2+12], [3+15, 4+18]]=[[11, 14], [18, 22]]. При A=diag(3, 1), x=(1, 1): Ax=(3, 1), BAx=(−1, 3). Bx=(−1, 1), ABx=(−3, 1). Пример существования только AB: A формы(2, 3), B формы(3, 4), AB формы(2, 4), BA невозможно из-за 4≠2.

```python
import numpy as np
X=np.array([[1,0,2],[0,1,3]]);W=np.array([[1,2],[3,4],[5,6]])
assert np.array_equal(X@W,[[11,14],[18,22]])
```

## M02-L05-A01

Оценки A=0, B=0.8, C=1. Top2=[C, B]. Из двух релевантных top1 содержит одного: recall=0.5; top2 обоих: recall=1. Нулевой запрос отклоняется, несовместимая размерность вызывает явную ошибку контракта. Для q=(1, 1) оценки A=C=1/√2≈0.7071, B=1.4/√2≈0.9899; сначала B, затем A и C по принятому правилу равенства.

```python
import numpy as np
D=np.array([[1.,0.],[.6,.8],[0.,1.]])
scores=D@np.array([0.,1.])
assert np.argsort(-scores,kind="stable").tolist()==[2,1,0]
relevant={1,2}; ranked=[2,1,0]
assert len(set(ranked[:1])&relevant)/len(relevant)==.5
assert len(set(ranked[:2])&relevant)/len(relevant)==1
```
