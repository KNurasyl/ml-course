# M00. Решения для самопроверки

Сначала сохрани собственную попытку. Совпадение числа без объяснения процесса не считается самостоятельным решением.

## M00-L01-A01

Получаем [−5, −2, 10]. При x=−1: 3×(−1)−2=−5; при нуле остаётся −2; при x=4: 12−2=10. Числа 3 и −2 фиксируют правило, а −1, 0, 4 являются входами. Ни один параметр не выбирался по известным правильным ответам, поэтому это применение модели. Новый вариант даёт [8, 2, −2].

## M00-L02-A01

Исходная модель даёт [8, −2] для входов [−2, 3]. Вариант b=1 даёт [5, −5]. Вариант w=−1, b=4 даёт [6, 1]. Артефакт может содержать architecture="linear_v1", feature="duration_seconds", w, b, version. При переводе секунд в миллисекунды вес нужно делить на 1000: тогда w_ms×x_ms=w_s×x_s. Смещение сохраняется.

## M00-L03-A01

A предсказывает [1, 3, 5], остатки [−1, −1, −1], MSE=1. B предсказывает [2, 3, 4], остатки [0, −1, −2], MSE=5/3. Выбирается A на данной таблице. Допустимо утверждение о меньшей наблюдаемой MSE; недопустимо обещание превосходства на всех будущих интервью. Для повторного y=[1, 3, 5] A имеет 0, B имеет 2/3.

## M00-L04-A01

Резюме меняет контекст вызова; проверка — фактически отправленный запрос. Методичка меняет корпус, но старый индекс может её не находить; проверяются версия индекса и результаты поиска. Обучение адаптера меняет параметры адаптера, базовые веса могут сохраниться; сравниваются артефакты и конфигурация обучения. Системная инструкция меняет вход; проверяется шаблон сформированных сообщений. Ни один из первых, второго и четвёртого случаев сам по себе не свидетельствует об оптимизации весов.

## M00-L05-A01

Преобразованный вход z=5−2=3, правильное предсказание 4×3+1=13. Без центрирования получится 4×5+1=21. Сервис технически вычисляет число, но нарушает контракт модели. Откат должен вернуть архитектуру, смещение подготовки, веса, смещение модели и версию предыдущего релиза. Для недоступного артефакта допустима явная ошибка временной недоступности; молчаливый случайный ответ недопустим.

## M00-HW01

A даёт [5,1,−5], MSE=0; B даёт [2,0,−3], MSE=14/3. Выбран A, новый ответ −7. B-вариант: первый кандидат точен, второй имеет MSE=2. При переводе минут в секунды можно сначала делить вход на 60, сохраняя веса; либо делить коэффициент w на 60, сохраняя b. Изменение единиц не является новым обучением, но должно быть частью новой версии контракта.

[Запускаемый полный ключ](../exercises/M00/run_hw.py); из корня: `.\.venv\Scripts\python.exe solutions\exercises\M00\run_hw.py`. Он сохраняет расчёты A/B/C отдельно от твоей работы. Полнота совпадения чисел не заменяет объяснение.

## Разбор расхождений

Проверь прежде всего смысл входов, порядок операций и условия сравнения. После исправления выполни указанный в модуле новый вариант. При другой корректной реализации допустимы небольшие различия плавающей арифметики, но не другой смысл метрики, разбиения или вывода.
